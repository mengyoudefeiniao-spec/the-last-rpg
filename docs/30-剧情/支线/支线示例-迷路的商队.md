# 支线示例 · 迷路的商队（`quest.side.caravan`）

> 本文件是**支线写作的模板示例**。展示一条支线如何与世界观、人物、跨世 flag 咬合。
> 对应随机事件 `event.folk.lost-caravan`（见 `../随机事件.md`），但本支线是它的**固定版**（主线第一世内必定可触发）。

## 一、概要

| 项 | 内容 |
| --- | --- |
| ID | `quest.side.caravan` |
| 所属卷 | 第一世（`story.vol1`） |
| 地点 | 东荒 · 青芜村外的官道 |
| 前置 | 完成 `quest.vol1.village` |
| 类型 | 支线（可选，影响第七世） |
| 主题 | **"一个路人，会在数百年后回来。"** |

## 二、触发条件

- 第一幕（`quest.vol1.village`）完成后，主角**离开青芜村**去往官道的任意时刻，**首次**触发。
- 权重固定为 100%（教学性质，确保玩家遇到），之后转为随机（见 `event.folk.lost-caravan`）。

## 三、参与人物

| 人物 | ID | 说明 |
| --- | --- | --- |
| 主角 | `char.hero.lingyue` | 凌越，约 14 岁 |
| 商队首领 | `char.npc.merchant-lead` | 中年，精于算计但心不坏 |
| 商队的孩子 | `char.npc.caravan-child` | 约 8 岁，**关键：随机存在（见下）** |
| 苏昭 | `char.suzhao` | 可选登场（若 `flag.bond.suzhao ≥ 1`，她会跟来） |

## 四、剧情段落（含"四件事"）

### 段落 1 · 求助（触发 / 参与 / 选择 / 结果）

- **触发**：主角走到官道岔口。
- **参与**：商队首领、孩子（若存在）。
- **内容**：商队因瘴气绕路而迷路，首领请求带路去青芜村。

- **玩家选择项**：
  1. **立刻答应**（无报酬要求）
  2. **谈报酬**（要灵石或干粮）
  3. **拒绝并指个方向**

- **结果**：
  | 选项 | 结果 | flag |
  | --- | --- | --- |
  | 1 | 商队感激；孩子在路途中亲近主角，讲起"自己的名字" | `flag.folk.caravanKind = true` |
  | 2 | 得 20 灵石；首领悻悻（不影响后续） | — |
  | 3 | 支线**终止**；夜里 20% 概率在路边发现商队残骸（**孩子死亡**） | `flag.folk.lostChild = true`（若发现残骸且孩子存在） |

### 段落 2 · 归途（不确定性点）

- **触发**：选择 1 或 2 后，带路途中。
- **不确定项**：`rng` 判定
  - 70%：平安抵达青芜村。
  - 30%：途中遭遇**一群低阶妖兽**（狼形灵兽），触发战斗。
- **内容**：若触发战斗——
  - 孩子在混乱中可能受伤或死亡（**再由 rng 判定**：主角保护及时则存活）。
  - **这里就是"不确定性"的核心教学**：玩家明明"只是好心带个路"，却可能付出代价。

- **玩家选择项**（仅战斗时）：
  1. **护住孩子** → 战斗中承受额外伤害，孩子存活 → `flag.folk.savedChild = true`
  2. **先杀妖兽** → 战斗更顺，但孩子有 50% 概率死亡 → `flag.folk.lostChild = true`
  3. **让商队首领自己护** → 首领受伤，孩子存活但首领怀恨（后续无影响）

### 段落 3 · 告别

- **触发**：抵达青芜村。
- **参与**：孩子（若存活）。
- **内容**：孩子把自己的**平安符**塞给主角（一件不起眼的小道具）。
- **结果**：
  - 若孩子存活 → 主角获得 `item.npc.pinganfu`（**第七世**：这枚平安符会以另一种形式，出现在一个陌生少年手中——那就是**转生后的孩子**）；并得到**一条游魂线索**（孩子说："我在路上捡到一块石头，它一直在响，我怕，就把它放回洞里了。"——**指向一处隐藏区域，不直接给游魂**）。
  - 若孩子死亡 → 主角只留下一句"没来得及说的话"，`flag.folk.lostChild = true`。

## 五、跨世回响（本支线的设计价值）

> 这条支线存在的唯一理由，是**让玩家亲手体验"世代转世"**。

| 若 | 第七世将出现 |
| --- | --- |
| 孩子存活（`flag.folk.savedChild`） | 一个少年在终局前找到主角："**我爷爷的爷爷说，很久以前有人救过他。**" → 触发 `ending.continue` 的**额外暖场文本** |
| 孩子死亡（`flag.folk.lostChild`） | 一个少年在终局前质问主角："**你当年为什么不救我？**" → 触发 `ending.balance` 的**额外沉重文本** |
| 支线未完成 / 拒绝（无 flag） | 该少年不出现；世界少了一份温度 |

> **羁绊门槛**：该少年只有与主角的羁绊达**生死之交**（`flag.bond.caravan-child ≥ 4`）时，才会在**镇蚀**时真正现身并肩。
> **这就是"选择要到第七世才显现"的具体样子。**

## 六、奖励与代价

| 项 | 内容 |
| --- | --- |
| 奖励 | 20 灵石 / 干粮 / `item.npc.pinganfu` / **一条游魂线索**（孩子存活时） |
| 代价 | 战斗中额外受伤；夜晚遇袭风险 |
| 羁绊收益 | `flag.bond.caravan-child` → 第七世该孩子的转生者是否成为同伴（需达**生死之交**） |
