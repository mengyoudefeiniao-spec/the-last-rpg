# 随机事件系统（不确定性设计）

> ID：`sys.random-events`。本文件定义"世界会自己动"的部分——**具有不确定性**的事件。
> 实现侧对应 `src/core/rng.ts`（可复现随机数）与 `src/world/`（触发器）。本文件只做**设计**。

---

## 一、设计哲学：「遁去的一」

世界观里，「大衍之数五十，其用四十有九」（`concept.remainder`）——总有**其一的余数不可测**。
随机事件系统就是那个"余数"。它服务三个目的：

1. **让每一世、每一次重开都不同**——对抗"我知道剧情"的疲劳。
2. **给「残魂」的预知留出被打破的空间**——主角的预知**不总是对的**。
3. **制造"意外的感情"**——一个随机出现又随机死去的小 NPC，往往比主线角色更让人记住。**他也是羁绊的来源。**

> **反面原则**：随机**不可影响主线的可达性**。主线关键节点（各卷的开场、终局、**世魂归位**）**必须确定触发**，随机只作用于**过程、细节、隐藏区域线索、可选奖励与情感**。

## 二、事件的解剖（结构）

| 字段 | 说明 |
| --- | --- |
| **ID** | `event.<地区>.<短横线名>`，如 `event.eastwild.stray-dog` |
| **类别** | 见下一节 |
| **触发条件** | 地点 / 卷 / 境界 / flag / 时间 |
| **权重** | 在事件池中的相对概率（`rng` 按权重抽取） |
| **冷却** | 同事件最短重现间隔（避免重复刷） |
| **参与人物** | 用规格化 ID |
| **玩家选择项** | 2–4 个，带明示或暗示的后果 |
| **结果** | 每个选项的结果，含 **flag 影响**与一次性 vs 永久 |
| **残魂线索 / 羁绊** | 是否指向**游魂的隐藏区域**；是否能**加深某段羁绊**（无则写"无"） |
| **不确定项** | 事件内部**还需再摇一次骰**的变量 |

---

## 三、事件类别（六类）

| 类别 | 前缀 | 说明 | 例子 |
| --- | --- | --- | --- |
| **天象** | `event.sky.*` | 天地异变，无善恶 | 灵雨、地动、血月 |
| **奇遇** | `event.luck.*` | 机缘，可遇不可求 | 洞府、古碑、遗宝 |
| **人事** | `event.folk.*` | 人与人际遇 | 求助、商队、口角、**结缘** |
| **灾祸** | `event.calamity.*` | 危险 | 兽潮、瘟疫、魔修越境 |
| **机缘** | `event.insight.*` | 修行相关 | 顿悟、传承、灵兽认主 |
| **异常** | `event.anomaly.*` | **仅主角偶发** | 「残魂回响」「错位词」「既视感」 |

> **「异常」是本作独有的一类**：只有畸轮者（主角）会遭遇。它把"轮回 + 残魂"两个主题做成**可遇不可求的随机体验**。

---

## 四、预知与偏转（本作随机性的关键机制）

1. **残魂碎片化**：预知只给**画面与情绪**，不给因果；**且必须收集过对应残魂**才会出现。
2. **世界会偏转**：若玩家**依据残魂改变了某个行为**，被改变的事件会**重新摇骰**——原本的"安全"可能变成"危险"。
3. **代价是错位**：残魂会**错位**——主角"想起"的现代画面与异世界**没有对应概念**，因此**预知常常无法翻译**成可用的情报。

> 这三层让"不确定性"成为**主题的一部分**：**你越想控制命运，命运越模糊。**

## 五、示例事件（8 个）

> `反` = 反面示例，`正` = 正面示例；**残魂线索**一栏标注该事件能否**指向游魂的隐藏区域**。

### 1. `event.sky.spirit-rain` — 灵雨（天象）
- **触发**：任意卷 · 野外 · 权重 3 · 冷却 3 天
- **内容**：青色灵雨落下，万物吐纳加速。
- **不确定项**：雨**持续几刻**（`rng` 1–3）——决定打坐收益倍率。
- **玩家选择**：① 就地打坐（收益 ×2~×4，但 roll 到 1 且有敌人 → 埋伏）② 继续赶路（避开埋伏）
- **残魂线索 / 羁绊**：无（10% 概率触发一次**错位词**独白，只作气氛）
- **主题呼应**：灵雨落处，主角会莫名想起现实世界的雨。

### 2. `event.luck.old-stele` — 半截古碑（奇遇）
- **触发**：第 1、3、7 卷 · 荒僻处 · 权重 1 · 仅一次
- **内容**：一截被苔藓覆盖的石碑，字迹模糊。
- **不确定项**：碑的内容由 `rng` 在三者间抽——
  - a. 轮回碑残段（**关键线索**）
  - b. 上古修士墓志（背景故事，给道具）
  - c. 蚀痕刻画（**危险**：触碰则**残魂被污染**）
- **玩家选择**：拓印 / 触摸 / 离开
- **残魂线索 / 羁绊**：roll 到 a → **指向一处游魂隐藏区域**（"碑上刻的那个方向，有东西在响"）
- **结果**：roll 到 c 且触摸 → `flag.anomaly.corrupted +1`（第七世拼合真相时会出现"假线索"）

### 3. `event.folk.lost-caravan` — 迷路的商队（人事）
- **触发**：任意卷 · 官道 · 权重 4
- **内容**：一队商队迷路，请求带路。
- **不确定项**：商队里**有一个孩子**（50%）——若有，途中遭遇战斗时孩子可能死亡。
- **玩家选择**：① 带路 ② 索要高价 ③ 拒绝
- **残魂线索 / 羁绊**：**能加深羁绊**——若在战斗中护住孩子（`flag.folk.savedChild`），该"路人"的羁绊会**跨越数百年延续到第七世**
- **主题呼应**：一个随机路人，可能在数百年后以另一副面孔回来。**这是"世代转世 + 羁绊"在随机系统里的体现。**

### 4. `event.calamity.beast-tide` — 兽潮（灾祸）
- **触发**：第 1、4 卷 · 山野 / 西荒 · 权重 2
- **不确定项**：**规模**（小/中/大）与**是否人为驱赶**（30%，牵连幽都）
- **玩家选择**：迎战 / 疏散 / 独自引开
- **残魂线索 / 羁绊**：规模「大」且迎战 → **可能发现通往某处游魂隐藏区域的裂缝**；共同迎战的同伴 → **羁绊 +1**
- **结果**：影响区域声望；发现"人为"则 `flag.volX.youduSeen = true`

### 5. `event.insight.sudden-awakening` — 顿悟（机缘）
- **触发**：任意卷 · 打坐 · 权重 2 · 冷却 10 天
- **不确定项**：顿悟来源——"本世修行"（安全）或"前世残魂"（**代价**：忘掉一件本世的琐事）
- **残魂线索 / 羁绊**：来源为"前世残魂"时，**指向一枚游魂的大致方位**（错位词变清晰）
- **叙事价值**：**记忆与修为，是同一种货币。**

### 6. `event.anomaly.soul-echo` — 残魂回响（异常 · 主角专属）
- **触发**：任意卷 · 权重 2 · **前置 `flag.soul.worldSouls ≥ 1`**
- **内容**：主角忽然"看见"某一段画面——有时是前世的自己，有时是**别人的**前世（蚀吞下的记忆）。
- **不确定项**：三段随机画面：a. 情绪（无信息）· b. 线索（推进主线）· c. 不认识的人生（**污染**）
- **玩家选择**：深究 / 压下 / 记录
- **残魂线索 / 羁绊**：选"深究"且 roll 到 b → **直接指向最近的游魂隐藏区域**
- **结果**：**最诱人的选择，代价最不可知。**

### 7. `event.sky.blood-moon` — 血月（天象）
- **触发**：第 5、6、7 卷 · 权重 2
- **不确定项**：**是否伴随蚀痕扩散**（20%）——若扩散，3 天内"异常"类事件权重翻倍
- **玩家选择**：蛰伏 / 趁势修行 / 探查源头
- **残魂线索 / 羁绊**：探查源头且发现蚀痕 → **+1 游魂污染风险**，但也可能**发现一枚游魂**
- **结果**：血月出现次数**在第七世被统计**（出现越多，终局越紧迫）

### 8. `event.folk.returning-stranger` — 回来的人（人事 · 跨世钩子）
- **触发**：第 2–7 卷 · 权重 2 · 前置：任意 `flag.bond.*` 曾置真
- **内容**：一个陌生人对主角说"我们见过"——而主角的残魂里**确实有一个模糊的影子**。
- **不确定项**：来者是 a. 前世帮过的人（**善**，且**羁绊 +1**）· b. 前世害过的人（**仇**）· c. 轮回司探子（**危险**）
- **结果**：**随机事件里最有分量的一类**——它让"每一世的因果与羁绊"在后续世代回响。

## 六、随机事件与残魂 / 羁绊的关系

| 目标 | 主要由什么事件类型服务 |
| --- | --- |
| **世魂**（主线） | 不由随机事件产出；每世临终**必然**归位 |
| **游魂**（隐藏区域） | 随机事件**不直接给**游魂，而是给**线索**（指向隐藏区域）——**找不找，是玩家的选择** |
| **羁绊** | `event.folk.*`（商队、回来的人）、`event.calamity.*`（共患难） |

> **设计意图**：残魂不长在"任务清单"上，而**长在世界里**。
> 玩家在打怪、赶路、帮人时**不经意**捡到残魂、**不经意**结交一个人——**这两件事，最后都会在第七世兑现。**

## 八、写作约束

1. 任何随机事件**不得**让主线节点变得不可达。
2. 每个"异常"类事件必须**至少有一个"代价"**。
3. 每个事件必须写明**残魂线索 / 羁绊**（无则写"无"）——这是七世关联性的检查项。
4. 随机事件**不直接发放世魂 / 游魂**（世魂是主线、游魂靠探索），只给**线索**与**羁绊**。
5. 概率与权重是**可调参数**，由 `src/config/balance.ts` 统一管理（`src/README.md` 约定）。
