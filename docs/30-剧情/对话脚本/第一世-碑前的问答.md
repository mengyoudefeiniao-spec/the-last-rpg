# 第一世 · 碑前的问答（`dlg.vol1.yunhe-stele`）

> 场景：`story.vol1` 第二幕 `quest.vol1.yunhe` —— 云鹤带凌越进山，见轮回碑残段。

## 三、节点表

### `n_start` · 进山
- **说话人**：（旁白）
- **文本**：云鹤走在前头，木杖点着石阶。山雾很大，凌越却觉得这条路**走过**——尽管他从没来过。
- **效果**：无
- **跳转** → `n_stele`

### `n_stele` · 碑
- **说话人**：（旁白）
- **文本**：一块半埋的青石，字迹被苔藓吃去大半。走近时，凌越的耳朵里"嗡"地一响——
  > **残魂触发**：一瞬的闪光里，他看见一个穿着奇怪衣服的人，低着头，对着一块**会发光的板子**叹气。
- **错位词**：凌越脱口而出——"……**编译**？"
  （山雾还在，这个词却在响。云鹤停下脚步，回头看他。）
- **效果**：`triggerSoulEcho('echo.first-glance')`——一次**残魂回响**（异常事件，**不产出残魂**；见 `../随机事件.md`）
- **跳转** → `n_yunhe_1`

### `n_yunhe_1` · 云鹤开口
- **说话人**：`char.yunhe`
- **文本**：你刚才，说了个什么词？
- **选项**：
  1. **"……没什么。"** → `n_deny`
  2. **"我好像……以前来过这里。"** → `n_admit`
  3. **"这石头，在说话。"** → `n_stone_speaks`

#### `n_deny`
- **说话人**：`char.yunhe`
- **文本**：（眯眼笑）撒谎的孩子，眉毛会动。
  - 你刚才说的那个词，老朽活了三千年，没听过。
- **效果**：无（云鹤看穿但不点破）
- **跳转** → `n_yunhe_key`

#### `n_admit`
- **说话人**：`char.yunhe`
- **文本**：来过？你今年十四。
  - ……
  - 有意思。**不是"记得"，是"认得"。**
- **效果**：`flag.trust.yunhe += 1`
- **跳转** → `n_yunhe_key`

该节点被选中后，`n_admit` 内追加一段**玩家可选**子选项：

- **子选项 A："师父，我为什么会记得别人的事？"**
  → **跳转** `n_knowledge_q`（进入"畸轮 / 残魂"问答）
- **子选项 B：（沉默）**
  → **跳转** `n_yunhe_key`

#### `n_stone_speaks`
- **说话人**：`char.yunhe`
- **文本**：（第一次收起了笑）**你说什么？**
  - ……孩子，站远些。
- **效果**：`flag.trust.yunhe += 1`；`flag.choice.vol1.stoneHeard = true`
- **跳转** → `n_knowledge_q`（**强制进入问答**，且云鹤更严肃）

### `n_knowledge_q` · "忘川不收的魂"
- **说话人**：`char.yunhe`
- **文本**：
  > 你问过我，人死后去哪。
  > 都去过**忘川**。洗掉记得的，忘掉舍不得的，然后重新做人。
  > ……
  > 可有些魂，忘川**不收**。
  > 它们记得。一直记得。记得一次又一次的疼。
- **选项**：
  1. **"那种魂，叫什么？"** → `n_answer`
  2. **"那……我会不会就是？"** → `n_self_doubt`
  3. **"师父，你怎么知道这些？"** → `n_about_yunhe`

#### `n_answer`
- **说话人**：`char.yunhe`
- **文本**：
  > 有个老词，叫**「畸轮」**。
  > 他们的记忆不会消失，只会**碎**——碎成一片一片，散在过去，也散在将来。
  > 老朽管那些碎片叫……**「残魂」**。
  > 捡得回来，人就还是那个人。捡不回来，就永远缺着一块。
  > ……我已很久没见过畸轮了。久到我以为，它只是传说。
- **效果**：`flag.memory.mentionDistorted = true`；`flag.memory.learnedSoulFragment = true`
  （**只记录"听过残魂"，不置 `flag.awareness.distorted`**）
- **跳转** → `n_yunhe_key`

#### `n_self_doubt`
- **说话人**：`char.yunhe`
- **文本**：（长久地沉默）
  - ……孩子，我答不了你。
  - **我守了三千年的东西，或许就是在等一个你。**
- **效果**：`flag.trust.yunhe += 1`
- **跳转** → `n_yunhe_key`

#### `n_about_yunhe`
- **说话人**：`char.yunhe`
- **文本**：（笑）徒弟问师父的底细，是不合规矩的。
  - 不过……我确实**活得太久了**。
  - 久到，我忘了自己是谁。
- **效果**：`flag.yunhe.hinted = true`（第七世"云鹤=畸轮之一"反转的伏笔）
- **跳转** → `n_yunhe_key`

### `n_yunhe_key` · 收尾
- **说话人**：`char.yunhe`
- **文本**：
  > 回去吧。**天黑前一定要到家。**
  > （凌越一愣——这句话，他好像在哪儿听过。）
- **效果**：`flag.bond.suzhao_hint = true`（**呼应苏昭的"灵魂指纹"**：她把这句话挂在嘴边；云鹤竟也说了一样的话 → 玩家第一次察觉"这句话有古怪"）
- **跳转** → `n_end`

### `n_end` · 结束
- **说话人**：（旁白）
- **文本**：下山的路，比来时短。凌越回头看了一眼那块石头。
  它安安静静的，像什么都没说过。
- **效果**：结束本脚本，返回 `quest.vol1.yunhe` 主线
- **跳转** → （结束）

## 四、条件与效果速查

| 效果 | 类型 | 含义 |
| --- | --- | --- |
| `triggerSoulEcho(id)` | 系统调用 | 触发一次"残魂回响"演出（异常事件，**不产出残魂**；见 `../随机事件.md`） |
| `flag.trust.yunhe += 1` | 状态 | 累积信任（跨世 flag） |
| `flag.memory.mentionDistorted` | 状态 | "听过畸轮这个词"的记录（**不等于**知道自己是畸轮） |
| `flag.memory.learnedSoulFragment` | 状态 | "听过残魂这个说法"的记录 |
| `flag.yunhe.hinted` | 状态 | 云鹤自曝身世的伏笔 |
| `flag.bond.suzhao_hint` | 状态 | "天黑前回家"这句话的第一次异样 |

> **设计要点**：本脚本**故意不置真** `flag.awareness.distorted`。玩家可以听到"畸轮""残魂"这些词，但**要到第一世终幕**（凌越之死）才真正确认。**"知道了词"和"知道自己就是"是两件事**——这是叙事悬念的纪律。

## 五、写作约束（对话脚本）

1. 每个节点**必须有明确的跳转**；除 `n_end` 外不允许悬空。
2. **条件与效果一律用规格化 ID / flag**，不写自然语言后果（"他很感动"）。
3. 台词的**说话人**必须给出 `char.*` ID；旁白用 `（旁白）`。
4. 任何**新出现的 flag**，必须在 `主线/00-主线总纲.md` 第四节「跨世 flag 与残魂系统」登记（若跨世）或本卷 flag 汇总登记（若本世）。
