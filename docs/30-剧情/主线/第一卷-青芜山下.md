# 第一世 · 青芜山下（`story.vol1`）

> **大衍历 0–31 年 · 东荒 · 青芜村（`place.qingwu`）**
> 主角：凌越（`char.hero.lingyue`）· 凡骨孤儿 · 约 12 → 31 岁
> 本卷是**教学卷**：建立世界、建立主角、"畸轮"的核心悬念，并**教会玩家四件事**：指令怎么用、残魂是什么、羁绊怎么结、**每一世的打法都不一样**。目标篇幅 = 全作最短的一卷。

---

## 一、本卷目标（给设计者的七问）

| 问 | 答 |
| --- | --- |
| 舞台在哪 | 东荒边陲的**青芜村**与背后的**青芜山**（山中藏无名古碑 = 轮回碑残段） |
| 主角是谁 | **凌越**，村中孤儿，灵根极劣（凡骨） |
| 他要什么 | 活下去；弄清"为什么只有我记得前世" |
| **该世专精指令** | 普攻 →（第二幕）**学会「法术」**——本世唯一的专精 |
| **归位哪枚世魂** | **①**——想起"……保存一下。" |
| **哪枚游魂藏在此地** | **③「缓存」**——青芜山**隐藏洞窟**；学得**「缓存体」** |
| **与谁结下羁绊** | **阿婆**（抚养之恩）、**苏昭**（通往"知己"的起点） |

> **教学重点（不解释，靠体验）**：
> ① **指令有限**——第一幕凌越只会"普通攻击"，第二幕才学会"法术"（**这一世不会有别的**）；
> ② 主角会冒出莫名其妙的**错位词**，错位词附近有**残魂**；
> ③ **羁绊**只有靠"一起扛过事"才能变深。

## 三、逐幕详案

### 序幕 · 醒在别人的身体里（`quest.vol1.prologue`）

- **触发条件**：游戏开始（从序章 `story.prologue` 交棒）。
- **参与人物**：凌越、村妇**阿婆**（`char.npc.grandma`）。
- **内容**：凌越在自己的（别人的）身体里醒来，六岁，满脑子不连贯的碎片——地铁、屏幕、一行没写完的代码。
- **★ 指令教学（负向）**：序幕的战斗（村中驱赶野狗）里，凌越**只有"普通攻击"和"防御 / 逃跑"**。
  玩家会本能地想找"法术"——**没有**。这就是第一世的开局：**除了挥拳，什么都不会。**
- **玩家选择项**：
  1. **说出来**：告诉阿婆自己"记得另一个世界"。→ 被当作撞邪（`flag.choice.vol1.spokeOut = true`）
  2. **藏起来**：把碎片埋在心里。→ 主角养成"观察与隐忍"的性格（`flag.choice.vol1.spokeOut = false`）
- **结果**：玩家第一次体验**「残魂」系统**（见 `../../10-世界/规则体系.md` 第六节）。
- **★ 第一次错位词**：凌越脱口而出——**"……我没事，就是……缓存满了。"** 阿婆一脸茫然。
- **★ 羁绊起点**：**阿婆**不会嫌弃他，只是把他搂紧了些。→ `flag.bond.grandma +1`

### 第一幕 · 村子与山（`quest.vol1.village`）

- **触发条件**：序幕结束，凌越 12 岁。
- **参与人物**：凌越、**苏昭**（`char.suzhao`，采药少女）、村民若干。
- **内容**：开放探索第一站。青芜村日常、后山的禁忌、"山里会说话的石头"的传说。
- **可探索**：
  - 村中 NPC 任务（采集、跑腿）——教学：RPG 基本交互。
  - **后山**：受惊的野猪群——**教学战斗（此时仍只有普攻）**。
  - **★ 藏有游魂的隐藏区域：青芜山隐藏洞窟**——入口被藤蔓遮住，鸣响着"嗡"声（错位词提示："……**缓存**？"）。
    拾得 **游魂③「缓存」** → 学得专属技能 **「缓存体」**（`skill.soul.cache`：暂存一次术法或伤害，稍后释放）。
- **玩家选择项**（关键）：
  - 遇野猪群时，残魂突然"闪回"一个**还没发生的画面**（苏昭被撞倒）。玩家可以：
    1. **相信预感，提前拦住苏昭** → `flag.choice.vol1.trustedForeboding = true`；`flag.bond.suzhao +1`
    2. **当它是幻觉** → 苏昭受伤 → `flag.choice.vol1.trustedForeboding = false`
- **★ 羁绊教学**：无论哪个选项，**凌越都为苏昭挡了一下**——羁绊**只在有代价的选择中加深**。
- **结果**：玩家第一次意识到"残魂能救命"，也第一次**用上一个"游魂技能"**。

### 第二幕 · 云鹤与碑（`quest.vol1.yunhe`）

- **触发条件**：完成第一幕，且凌越在青芜村已有一定声望。
- **参与人物**：凌越、**云鹤真人**（`char.yunhe`）、苏昭。
- **内容**：
  - 云鹤云游至青芜村，一眼"看穿"了凌越的不寻常。
  - **★ 关键教学：凌越拜入云鹤门下，学引灵之法 —— 学会「法术」。**
    > 这是本卷的**正向指令教学**：从这一刻起，玩家战斗里多了"法术"这一项。
    > 云鹤会明确说一句：**"你这一世，学的就是这个。"**（为后面"每世打法不同"埋线）
  - **关键场景**：云鹤带凌越进山，见到**那座会说话的石头**——**轮回碑**（`item.stele`）残段。
  - 凌越近碑时，冒出**第三个、也是最重的一个错位词**（见 `../对话脚本/第一世-碑前的问答.md`）。
- **关键对话**（见 `../对话脚本/第一世-碑前的问答.md`）：
  - 云鹤第一次说出"**有些人的魂，忘川不收**"。
  - 云鹤第一次点破**「残魂」**："你记得的那些，是碎掉的**你自己**。捡回来，你就是完整的了。"
- **玩家选择项**：
  1. **追问自己是不是"畸轮"** → 云鹤不答，但记下了（`flag.trust.yunhe +1`）
  2. **转而问苏昭的事** → "你倒先想着别人"（`flag.bond.suzhao +1`）
  3. **什么都不问** → 云鹤更忧心（`flag.trust.yunhe +0`）
- **★ 羁绊**：这一世的云鹤成为凌越的**长者与引路人**（`flag.bond.yunhe` 起步）。
- **结果**：云鹤留下伏笔——"**我守了三千年的东西，或许就是在等一个你。**"

### 第三幕 · 山下的阴影（`quest.vol1.shadow`）

- **触发条件**：凌越 24 岁，引灵境后期（本卷封顶，凡骨上限）。
- **参与人物**：凌越、云鹤、苏昭、**幕后人**（`char.npc.fangshi`，实为**幽都**派来寻碑者）。
- **内容**：
  - 青芜山**妖兽之乱**——表面天灾，实为幕后人**破坏护阵、引妖兽下山**，好趁乱取走碑残段。
  - 凌越凭残魂的"预感"（与**法术 + 缓存体**）多次预警，成为村中主心骨。
- **玩家选择项**（本卷最重要的选择之一）：
  1. **拆穿幕后人**：需集齐前两幕线索。→ 幕后人暴露，但**云鹤必须出手**（违职），被碑反噬（`flag.trust.yunhe +1`，`flag.bond.yunhe +1`）
  2. **优先救人**：放弃追查，全力疏散村民。→ 幕后人带着碑残段逃走（`flag.vol1.villainEscaped = true`，第七世回收）
- **结果**：妖兽之乱平息，但**云鹤被碑"召回"**（留下一句"我还会在别处见你"）。
- **★ 羁绊代价**："先救人"意味着**放弃追查**——**羁绊的选择总是要付出一件事**。
- **留下的钩子**：幕后人逃走时的半句话——"**劫主说，畸轮的那个人，一定会来。**"

### 终幕 · 天黑前回家（`quest.vol1.finale`）

- **触发条件**：第三幕结束，大衍历 31 年，青芜山**地脉崩塌**。
- **参与人物**：凌越、苏昭。
- **内容**：
  - 山体崩塌，村口的路断成两截，碎石吞向村子。
  - 凌越已到引灵境极限，**他救不了所有人**。
  - **关键台词**（苏昭）："凌越，天黑前一定要回家。"
- **玩家选择项**（终局抉择）：
  1. **先救苏昭** → 她活下来（`flag.bond.suzhao +2`），凌越力竭而死
  2. **先救村民** → 苏昭与村民皆活，但这一世的"约定"被打破（`flag.vol1.kepthPromise = false`）
  3. **冲回去拿那半块碑残段**（若第三幕选过"救人"，碑残段已被抢走，此选项**灰掉**）→ 残段随灵魂进入轮回（`flag.vol1.carriedStele = true`）
- **结果**：
  - 凌越死。灵魂离体，**第一次看见"界间"**（`place.between`）。
  - **★ 第 ① 枚世魂归位**：在界间，凌越想起了"沈述"这个名字。
    > 他想起来的第一句话，是自己在现实里最后一次合上电脑时说的：
    > **"……保存一下。"**
  - 一个**看不清面孔的声音**（后期揭示为殷无咎）在界间对他说：
    > "别急着走。"
    > "你还没想起来——你为什么会在这里。"
  - **`flag.awareness.distorted = true`**。转生 → 第二世（`story.vol2`）。
  - **★ 过场提示（元叙事）**：界间过场里出现一行提示——
    > "**下一世，你会失去这一世的法术。**"
    > （**第一次预告"每世打法不同"**，让玩家有心理准备，并期待第七世。）

## 四、本卷的"不确定性"锚点

> 本卷是随机事件系统的**教学卷**，随机性刻意做得**温和且可理解**（见 `../随机事件.md`）：

- 第一幕后山遭遇：**触发哪一组野猪 / 有几只**，由 `rng` 决定。
- 第二幕云鹤现身地点：**村口 / 山道 / 碑前**三选一随机，影响线索顺序。
- **隐藏洞窟的位置随机**（后山三处洞口之一）——**但必然可找到**（教学保证）。
- 关键 NPC（阿婆、方士）的**性格细节随机生成**——影响玩家对村庄的"情感依附"。
