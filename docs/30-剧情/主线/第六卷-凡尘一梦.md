# 第六世 · 凡尘一梦（`story.vol6`）

> **大衍历 330–352 年 · 中州 · 大衍朝（`faction.dayan-court`）** · 时长目标 **110 分钟**
> 主角：柳眠（`char.hero.liumian`）· 凡人女子
> 本章性格：**人情 / 群像**——全作最"暖也最痛"的一章。

---

## 一、本卷目标（七问）

| 问 | 答 |
| --- | --- |
| 舞台在哪 | 中州 · 大衍朝的**坊市、宫城、城郊** |
| 主角是谁 | **柳眠**，摊贩之女，**无灵根**，没有任何修为 |
| 她要什么 | 作为一个**最弱的人**，还能改变什么 |
| **本卷专精** | 普攻 ＋ **阵法调整**（**战斗外 · 战前阵容 / 站位**；**每世重置**） |
| **归位哪枚世魂** | **⑥**——想起医院的走廊、一个未接来电 |
| **哪枚游魂藏在此地** | **⑥「分支」**——**大衍朝藏书阁**；学得**「分支诀」** |
| **与谁结下羁绊** | **周戍 / 孙婆婆 / 阿灰**（生死之交）· 宫女**苏昭** |

> **本卷的性格**：**一场"必须赢"的战斗都没有。**
> 全卷**没有战斗成长**——你只有**人**，和**把人放对位置**的本事。
> 这是全作**情绪最低、也最暖**的一章。

## 三、逐幕详案

### 幕 1 · 乱世（20 分 · `quest.vol6.chaos`）

- **触发**：第五世终幕 → 界间 → 转生中州。
- **参与人物**：柳眠（`char.hero.liumian`）、坊市街坊若干。
- **内容**：
  - 柳眠醒来，**是个在坊市摆小摊的姑娘**。
  - **★ 关键教学（负向）**：战斗里她**只有「普攻」和「防御 / 逃跑」**——
    **连"法术"都没有**（无灵根）。**这是全作最"废"的开局。**
  - **世界观（凡人视角）**：宗门高高在上，王朝**苛税如虎**，边关在败，**瘟疫在来**。
- **玩家操作**：**没有战斗**——只有**生存**：摆摊、进货、应付差役、给邻居帮把手。
- **玩家选择项**：
  1. **多赚一点钱** → 柳眠手头宽裕，但**得罪街坊**（`flag.vol6.rich = true`）
  2. **帮街坊一把** → 赚得少，但**有人记她的好**（`flag.bond.folk +1`）
- **结果**：无论哪条，**大疫**与**兵乱**将至。

### 幕 2 · 三个人（25 分 · `quest.vol6.three`）

- **触发**：坊市乱象渐起。
- **参与人物**：柳眠、**周戍**（`char.npc.zhoushu`）、**孙婆婆**（`char.npc.sunnainai`）、**阿灰**（`char.npc.ahui`）。
- **内容**：**群像建立**——三人**依次登场**，各有一段**小故事**：
  - **周戍**：他在坊市门口挡下几个抢粮的兵，**独眼看着柳眠说"你站我后面"**。
  - **孙婆婆**：瘟疫里，她**把最后一包药给了仇家**。
  - **阿灰**：他**跑了十里路**，只为把一封信送到。
  - **★ 设计要点**：这三段**都短**，但**都不煽情**——**善良是他们的日常，不是他们的宣言。**
- **玩家选择项**（每人一次）：
  1. **拿出自己的一点口粮/药** → `flag.bond.<成员> +1`
  2. **什么也没做** → 但他们**依然会护着你**（**这才是本卷要说的**）
- **结果**：四人成为一伙。**兵乱来了**——坊市要守不住了。

### 幕 3 · 排兵布阵（25 分 · `quest.vol6.formation`）★ 重心之一

- **触发**：柳眠要带一点人**护着老弱撤走**。
- **内容**：**阵法调整系统的完整教学**（**战斗外**）：
  - 玩家把**周戍 / 孙婆婆 / 阿灰**放进**1 / 2 / 3 号位**，体验不同加成：
    | 位置 | 谁站 | 加成 |
    | --- | --- | --- |
    | **1 号位** | 周戍 | **输出** —— 他挡在最前 |
    | **2 号位** | 孙婆婆 | **治疗** —— 她在后面把人拽回来 |
    | **3 号位** | 阿灰 | **速度** —— 他跑最快，先出手 |
  - **★ 教学方式**：**不是教程弹窗**，而是**三段护卫战**——玩家**自己试错**，并在战后**听三人对彼此的评价**（"老头站前面，我放心""婆婆在后面，我不怕"）。
  - **★ 与速度的关系**：把阿灰放 3 号位，**先手**能救下更多的人（**手感上直接可感**）。
- **玩家选择项**：
  1. **让三人分守三处** → 救下更多人，但**三人都有危险**
  2. **让三人护一处** → 更安全，但**别的地方死了人**（`flag.vol6.savedFewer = true`）
- **结果**：
  - 无论哪条，**柳眠学会了"把人放在对的位置上"**。
  - **拾得游魂⑥「分支」**（大衍朝藏书阁）→ 学得**「分支诀」**。

### 幕 4 · 苍生（25 分 · `quest.vol6.many`）★ 重心之一

- **触发**：撤到城郊，遇上**从宫里逃出来的宫女——苏昭**（`char.suzhao` 第六世身份）。
- **参与人物**：柳眠、苏昭、周戍、孙婆婆、阿灰、大量难民。
- **内容**：**本卷的剧情与情绪核心**：
  - **苏昭**（宫女）**和柳眠一样是凡人**。她不认得柳眠，但两人**一见如故**。
  - **★ 关键台词**（苏昭）：
    > "阿眠，你说人活一辈子，到底图什么？"
    > "我啊……我就图**天黑前，有人等我回去**。"
  - **★ 打碎幻觉（本卷的主题动作）**：
    柳眠（也就是主角）在此处会**第一次真正意识到**：
    > "……我一直在等下一世。"
    > "**可她只有这一世。**"
    > "**他们三个，也只有这一世。**"
  - **苍生之苦**：难民营的**瘟疫、饥饿、哭声**——**这里没有战斗，只有选择**：
    **有限的药、有限的口粮，给谁？**
- **玩家选择项**（**本卷最重的选择**）：
  1. **优先救孩子** → 老人死去，**周戍沉默了一整夜**
  2. **优先救老人** → 孩子死去，**孙婆婆再没说过一句话**
  3. **平均分** → 都活得艰难，但**没有人被彻底放弃**（`flag.vol6.fairShare = true`）
- **结果**：**没有"好选项"**。这是本卷要给玩家的东西——**"最弱的人"没有能力让所有人活下去。**

### 幕 5 · 覆灭（15 分 · `quest.vol6.finale`）

- **内容**：
  - **大衍朝覆灭之劫**：宫城崩塌，兵乱与蚀痕同时降临。
  - 柳眠**只是一个凡人**——她做不了什么"大事"，她只能：**把能撤的人撤走**。
  - **★ 关键处理（不煽情）**：三人**不一定会死**，但他们**未必都能活**：
    | `flag.bond.<成员>` | 结果 |
    | --- | --- |
    | ≥3 | 该成员**护着柳眠活了下来**（第七世以转生者回归） |
    | <3 | 该成员**死在乱中**（第七世不会出现） |
  - **★ 第 ⑥ 枚世魂归位**：在界间，他想起的是——
    > **医院的走廊、一个未接来电。**
    > 他想起自己在现实里**最后那段日子**：一个人躺在病床上，手机响过一次，**他没接**。
    > 后来他才知道，那是**他放弃的那个合伙人**打来的。
  - **这一世的第 6 阶是情绪最低点**——主角**不再说话**。
  - **`flag.soul.worldSouls +1`**（阶 6）。转生 → 第七世。
  - **★ 过场预告（全作最重的一句）**：
    > "**下一世是最后一世。**"
    > "**你会想起所有的事——包括那些你不想想起的。**"

## 四、本卷"不确定性"锚点

- 幕 2 三人**登场的顺序随机**。
- 幕 3 三段护卫战的**敌人配置随机**（但不改变"阵型教学"的核心）。
- 幕 4 难民营的**具体苦难事件随机抽取**（瘟疫 / 哄抢 / 骨肉分离）。
