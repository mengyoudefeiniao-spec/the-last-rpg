# 第二世 · 剑冢十年（`story.vol2`）

> **大衍历 60–95 年 · 中州 · 太玄剑宗、剑冢（`place.jianzhong`）** · 时长目标 **100 分钟**
> 主角：谢无衣（`char.hero.xiewuyi`）· 上等灵根 · 剑修
> 本章性格：**战斗 / 试炼**——全作手感最"爽"的一章。

---

## 一、本卷目标（七问）

| 问 | 答 |
| --- | --- |
| 舞台在哪 | 中州 · **太玄剑宗**（`faction.taixuan`）与**剑冢** |
| 主角是谁 | **谢无衣**，外门弟子，上等灵根 |
| 他要什么 | 变强；找到"轮回碑"的下落；弄清"为什么我记得的事，越来越清楚" |
| **本卷专精** | 普攻 · **特技** · **灵宝**（**剑宗重武轻术，不会法术**） |
| **归位哪枚世魂** | **②**——想起地铁、耳机、拥挤的人群 |
| **哪枚游魂藏在此地** | **①「编译」**——**剑冢深处**；学得**「编译符」** |
| **与谁结下羁绊** | 师兄**裴照**（`char.npc.peizhao`）——**生死之交** |

> **本卷的"爽"**：这是**唯一一卷从第一分钟就能打**的——剑修的手感、试炼的节奏、本命灵宝的获得。
> 但它也是**第一次让玩家尝到"打不赢"**：终幕的封印之役，主角**必死**。

## 三、逐幕详案

### 幕 1 · 外门弟子（15 分 · `quest.vol2.outer`）

- **触发**：第一世终幕结束，界间过场后转生。
- **参与人物**：谢无衣（`char.hero.xiewuyi`）、外门执事、师兄**裴照**（`char.npc.peizhao`）。
- **内容**：
  - 谢无衣醒来，**这一世他有上等灵根**——引气入体的感觉与第一世的"凡骨"截然不同（**手感反差**）。
  - **★ 关键教学**：战斗里出现了 **「特技」** 选项（第一世只有"法术"）。
    系统**不解释**，只让玩家打一场教学战斗——**"啊，这一世我不用法术，我用剑。"**
  - 界间过场里那句预告兑现：**"你失去了这一世的法术"**（玩家已经历过）。
- **玩家选择项**：
  1. **主动读取残魂**（第一世终幕解锁的能力）→ 画面闪过"地铁、耳机"→ `flag.vol2.readFragment = true`
  2. **不去碰它** → 主角说"这一次，我想先做个普通人"→ `flag.vol2.readFragment = false`（后续与裴照的对话更轻松）
- **结果**：无论哪条，谢无衣都被执事分到**外门第七组**——与**裴照**同组。

### 幕 2 · 剑冢试炼（30 分 · `quest.vol2.trial`）★ 本卷重心

- **触发**：谢无衣入外门半年，宗门**剑冢试炼**开始。
- **参与人物**：谢无衣、裴照、其他外门弟子若干、掌门**慕清和**（`char.npc.muqinghe`，远观）。
- **内容**：**连续试炼**，共 **4 关**，难度递增（这是本卷的战斗主体）：
  1. **石剑阵**：教学关——练习"特技"的连招。
  2. **剑灵**：会闪避的对手——逼玩家用**特技**而非普攻。
  3. **同门切磋**：与裴照对练（**可输**，输赢影响对话）。
  4. **剑冢深处**：试炼的最后一关——**这里藏着游魂①「编译」**，且有一只**"不被记录在册"的剑灵**（宗门不知道它的存在）。
- **玩家选择项**（第 4 关）：
  1. **按规矩退出** → 稳妥通关，但与"剑灵"擦肩而过
  2. **追进去** → 遭遇**失控剑灵**（高难战斗）；胜后可拾得**游魂①「编译」**（`flag.soul.drifting +1`）→ 学得**「编译符」**（多符合一）
  3. **拉上裴照一起进** → 难度降低，但**裴照因此受重伤**（`flag.bond.peizhao +1`，为幕 4 的牺牲埋线）
- **结果**：
  - 试炼结束，谢无衣**拔出了属于自己的剑**——**本命灵宝**（`art.spiritTreasure.natal`）。
    > 这是本卷"爽点"的顶点：**第一次拥有灵宝**。它会在第七世"认出"主角（`item.natalTreasure`）。
  - 掌门慕清和看了他一眼，说了一句不咸不淡的话："剑是好剑。就是人，太急了。"

### 幕 3 · 同门十年（20 分 · `quest.vol2.brotherhood`）

- **触发**：试炼之后，十年修行（时间跳跃）。
- **参与人物**：谢无衣、裴照、外门第七组众人。
- **内容**：**低强度、高情感**的一段——这是本卷的"呼吸"。
  - 与裴照的日常：练剑、喝酒、吵架、和好。
  - **★ 羁绊机制教学**：玩家的选择会**实质改变**羁绊值：
    1. **替裴照顶罪**（他打碎了门规禁物）→ `flag.bond.peizhao +2`（**这是通往"生死之交"的关键一步**）
    2. **让他自己认** → 裴照被罚，但他反而敬重主角 → `flag.bond.peizhao +1`
    3. **装不知道** → `flag.bond.peizhao +0`（第七世他不会来）
  - **苏昭线**：谢无衣在外门见到一名**新入门的外门女弟子**（`char.suzhao` 第二世身份）。
    她**不记得**他。玩家可以选择：
    1. **主动接近** → `flag.bond.suzhao +1`
    2. **远远看着** → 主角说"这一世……让她过自己的日子吧"→ `flag.bond.suzhao +0`
- **结果**：十年过去。北冥的封印**开始松动**——宗门征召弟子北上。

### 幕 4 · 北冥封印之役（25 分 · `quest.vol2.seal`）

- **触发**：宗门征召。
- **参与人物**：谢无衣、裴照、慕清和、剑宗弟子百余人。
- **内容**：**本卷的战斗高潮**——一场**守阵战**：
  - 玩家要**守住封印阵眼**若干回合，一波波"蚀痕"渗出的异兽涌来。
  - **失败条件**：阵眼被破（会重置到本幕开始）。
  - **裴照的命运取决于羁绊**：
    | `flag.bond.peizhao` | 结果 |
    | --- | --- |
    | ≥3（生死之交） | 裴照**替主角挡下致命一击**而死——**第七世他会以转生者身份回来** |
    | 1–2 | 裴照重伤但活下来，战后离开宗门 |
    | 0 | 裴照**没来北冥**；主角身边无人，孤军死守（**更孤独，也更冷**） |
- **玩家选择项**（本卷最重要的选择）：
  1. **以本命灵宝封住阵眼** → 封印暂时稳住，但**灵宝受损**（第七世回收时它"记得"主角的更少）
  2. **以自身神识硬撑** → 封印稳住，**主角神魂受损**（第七世开场会有"残魂更难读"的代价）
  3. **让慕清和决断** → 掌门出手，宗门付代价，**主角的死亡方式改变**（更"被牺牲"）
- **结果**：无论哪条，封印**只是暂时稳住**。而当夜，**蚀痕再度爆发**——谢无衣力竭而亡。

### 幕 5 · 终幕 · 剑落（10 分 · `quest.vol2.finale`）

- **内容**：
  - 谢无衣倒在雪里，本命灵宝插在他身边，**剑身嗡鸣不止**（它不舍）。
  - **★ 第 ② 枚世魂归位**：在界间，他想起的不是自己怎么死的，而是——
    > **地铁、耳机、拥挤的人群。**
    > 他想起自己曾在一个挤得喘不过气的早高峰里，戴着耳机，听着歌，觉得"活着真累"。
    > 然后他想起：**"可那时候，我至少还活着。"**
  - **界间的声音**（殷无咎）：
    > "你这一世，打得不错。"
    > "可惜——**他们都不记得你了。**"
  - **`flag.soul.worldSouls +1`**（阶 2）。转生 → 第三世。
  - **★ 过场预告**："下一世，你会失去这一世的剑。"

## 四、本卷"不确定性"锚点

- 剑冢试炼第 4 关：**剑灵的数量与属性**随机（1–3 只）。
- 幕 3 的日常事件**随机抽取**（练剑 / 喝酒 / 吵架），影响裴照的**性格细节**。
- 幕 4 守阵战的**敌人波次**随机——但波数固定（不改变难度上限）。
