# 第四世 · 西荒御兽（`story.vol4`）

> **大衍历 210–248 年 · 西荒 · 万兽山（`faction.wanshou`）、蛮族诸部** · 时长目标 **110 分钟**
> 主角：拓跋野（`char.hero.tuobaye`）· 御兽者
> 本章性格：**养成 / 羁绊**——全作最"慢"的一章。

---

## 一、本卷目标（七问）

| 问 | 答 |
| --- | --- |
| 舞台在哪 | 西荒 · **万兽山**、草原蛮族诸部 |
| 主角是谁 | **拓跋野**，蛮族少年，沉默、耐疼 |
| 他要什么 | 追寻"**归墟**"（`place.guixu`）——**轮回到底有没有尽头？** |
| **本卷专精** | 普攻 · **捕捉** · **召唤**（靠兽为生，**不修灵宝**） |
| **归位哪枚世魂** | **④**——想起深夜的显示器、咖啡、一个没改完的 bug |
| **哪枚游魂藏在此地** | **⑤「协议」**——**万兽山禁地**；学得**「契灵协议」** |
| **与谁结下羁绊** | 契约灵兽**雪狼·巴音**（`creature.bayin`）· 可汗之女**苏昭**（`char.suzhao`） |

> **本卷的性格**：**慢**。全卷最长的部分是**捕捉与培育**——
> 玩家要花大量时间**陪一只兽长大**，然后在终幕看它为自己挡下兽潮。
> **这是"羁绊"第一次不靠人、只靠陪伴建立起来。**

## 三、逐幕详案

### 幕 1 · 蛮族少年（15 分 · `quest.vol4.wild`）

- **触发**：第三世终幕 → 界间 → 转生西荒。
- **参与人物**：拓跋野（`char.hero.tuobaye`）、部族萨满、可汗之女**苏昭**（`char.suzhao`，本世身份）。
- **内容**：
  - 拓跋野在**草原部族**长大，**这一世不是修士，是猎人**。
  - **★ 关键教学**：战斗里出现 **「捕捉」** 与 **「召唤」**，**但没有"法术/特技/法宝/灵宝"**。
    > "我这一世，**连剑都不拿**。"
- **玩家选择项**：
  1. **按部族规矩，独自入山**（成年礼）→ 硬核开局
  2. **接受萨满的护符** → 降低前期难度，但萨满**多嘴**（埋幕 4 线索）
- **结果**：拓跋野进入**万兽山**。

### 幕 2 · 入山（20 分 · `quest.vol4.mountain`）

- **参与人物**：拓跋野、万兽山守山人。
- **内容**：
  - **教学：捕捉**——先用一场弱兽战教会"削弱 → 缔结契约"。
  - **教学：召唤**——教会"战前编队、战时召唤"。
  - **万兽山禁地**：山门深处有一处**不许进**的地方（**游魂⑤「协议」藏在那儿**）。
- **玩家选择项**：
  1. **守规矩，不窥探禁地** → 安全，但错过游魂线索
  2. **偷偷进去看一眼** → 触发**守山人冲突**（`flag.vol4.sawShrine = true`，幕 3 会得到额外帮助）

### 幕 3 · 巴音（35 分 · `quest.vol4.bayin`）★ 本卷重心

- **触发**：拓跋野在雪山里捡到一只**受伤的白狼幼崽**。
- **内容**：**全卷最长、最慢的一段**——**养成**：
  - **喂养 / 训练 / 受伤 / 疗伤 / 第一次并肩作战**，跨越**数年**（时间随培育进度推进）。
  - **巴音**（`creature.bayin`）会随玩家的照顾**性格成长**（亲人 / 警惕 / 沉默——由玩家行为决定）。
  - **★ 系统教学**：这一段教会玩家**"羁绊不能靠刷，靠一起扛事"**——喂食涨不了多少，**一起战斗、一起受伤才涨**。
- **玩家选择项**（多次累积）：
  1. **把最好的肉给巴音** → 巴音亲近，但主角长期半饿（`flag.bond.bayin +1`）
  2. **自己先吃饱** → 巴音平淡（`flag.bond.bayin +0`）
  3. **带着它去冒险**（危险但涨得快）→ `flag.bond.bayin +2`，有受伤风险
- **结果**：
  - 巴音成年。**拓跋野成了唯一能和它并肩的人**。
  - **拾得游魂⑤「协议」**（万兽山禁地，若幕 2 探过则更顺）→ 学得**「契灵协议」**（与灵兽缔结临时共斗契约）。
  - **苏昭线**：可汗之女 **苏昭** 来找他——**这一世她是"敌对的部族"的人**。
    玩家选择：
    1. **把归墟的线索告诉她** → `flag.bond.suzhao +2`
    2. **隐瞒** → `flag.bond.suzhao +0`
    > 无论哪条，她都会说："**天黑前，我得回营。**"（**灵魂指纹**第二次触发）

### 幕 4 · 归墟之路（25 分 · `quest.vol4.guixu`）

- **触发**：拓跋野带着巴音，**横穿西荒**去找"归墟"。
- **内容**：
  - **探索**：穿越草原、戈壁、盐湖，每一段都有**西荒民俗与"死者去哪儿"的传说**。
  - **核心发现**：**归墟不是"轮回的终点"**——它更像一个**"渡口"**：
    > "归墟之下，是忘川；忘川之下，什么都没有。"
    > ——**那么，被忘川洗掉的记忆，去哪了？**
  - **剧情**：拓跋野第一次意识到：**"我记住的东西，本该被洗掉。"**（呼应残魂机制）
- **玩家选择项**：
  1. **继续深入归墟** → 见到一次**"忘川的倒影"**（`flag.vol4.sawWangchuan = true`，第七世有额外对话）
  2. **转身回去** → 保住性命，但留下一句"我没敢看"
- **结果**：无论哪条，**兽潮**来了。

### 幕 5 · 兽潮（15 分 · `quest.vol4.finale`）

- **内容**：**本卷的战斗高潮**——但**大概率打不赢**：
  - 兽潮由**蚀痕驱动**（不是自然现象），规模远超想象。
  - **巴音的命运取决于羁绊**：
    | `flag.bond.bayin` | 结果 |
    | --- | --- |
    | ≥3 | 巴音**挡在主角身前而死**——**第七世它会被"召唤"回来** |
    | 1–2 | 巴音重伤存活，但再不能战 |
    | 0 | 巴音**跑了**（兽的求生本能）；主角**独自迎向兽潮** |
  - **★ 第 ④ 枚世魂归位**：在界间，他想起的是——
    > **深夜的显示器、咖啡、一个没改完的 bug。**
    > 他想起自己当时想："**再改一版就好了。**"
    > 然后他想起：**"可我从来没改完过任何一版。"**
  - **`flag.soul.worldSouls +1`**（阶 4）。转生 → 第五世。
  - **★ 过场预告**："下一世，你会变成**你最不想成为的那种人**。"

## 四、本卷"不确定性"锚点

- 巴音幼崽的**初始性格**随机（胆小 / 好动 / 孤僻）——影响培育中的对话与事件。
- 幕 4 的三段旅途的**顺序与遭遇随机**。
- 幕 5 兽潮的**规模由玩家幕 3 培育进度微调**（不是纯运气）。
