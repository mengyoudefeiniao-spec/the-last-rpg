# 第七世 · 终末之轮（`story.vol7`）

> **大衍历 380 年 – 现在 · 幽冥 · 忘川渡（`place.wangchuan-crossing`）、归墟、封蚀之阵（`place.seal`）** · 时长目标 **120 分钟**
> 主角：沈述（`char.hero`，**终于用回自己的名字**）
> 本章性格：**决战 / 收束**——全作的高潮与终点。

---

## 一、本章目标（六问）

| 问 | 答 |
| --- | --- |
| 舞台在哪 | 幽冥 · **忘川渡 → 归墟 → 封蚀之阵**（一条向下的路） |
| 主角是谁 | **沈述**——不是凌越、不是谢无衣，**是那个做游戏的人** |
| 他要什么 | 集齐残魂 → 镇蚀 → **决定轮回的归宿** |
| **本章专精** | **全部指令 + 自由组合 = 重构术**（`art.reforge`） |
| **残魂** | 补收集齐 **6 世魂 + 6 游魂**（前六世漏掉的在这里补） |
| **与谁并肩** | 前六世所有**生死之交 / 知己** |

> **本章的性格**：**收束**。前六世埋的每一条线，都在这里收口。
> **注意**：第七世**不产出新世魂**（它是"当下"）——但它是**"最后一世"**。

## 三、逐幕详案

### 幕 1 · 醒来（20 分 · `quest.vol7.wake`）

- **触发**：第六世终幕 → 界间 → 第七世。
- **内容**：
  - 沈述醒来——**这一世，他知道自己是谁**。
  - **★ 重构术教学**：战斗界面里，**所有指令同时出现**
    （普攻 / 法术 / 特技 / 法宝 / 灵宝 / 召唤 / 捕捉 / 防御 / 逃跑），
    **还有前六世的战斗外系统**（炼魂 / 阵法调整）。
    > 玩家此时才真正明白前六世"每世少一点"的意义——**现在是全都回来了。**
  - **★ 序章呼应**：如果序章选过"**一起推门**"（`flag.prologue.pushedTogether`），
    沈述会在此处看着自己的手说一句：
    > "……那扇门，我这次**是和人一起推的**。"
- **玩家选择项**：
  1. **先去看"那款游戏"** → 主角用第七世的眼睛"重看"《The Last RPG》（**元叙事回响**）→ `flag.vol7.reread = true`
  2. **直接上路** → 更快进入主线
- **结果**：沈述踏上**向下**的路（忘川渡 → 归墟 → 封蚀之阵）。

### 幕 2 · 记忆回廊（20 分 · `quest.vol7.corridor`）

- **触发**：忘川渡。
- **内容**：**补收漏掉的残魂**：
  - 忘川渡有一条**"记忆回廊"**——走过它，就能**重新进入前六世的某个场景**（限时）。
  - 前六世**漏掉的游魂**（隐藏区域没找到的）可以在这里补收。
  - **★ 设计要点**：**不惩罚**漏收的玩家——但**补收要花时间**（挤占幕 3 的练阵时间）。
- **玩家选择项**：
  1. **尽量补全**（花 15 分）→ 残魂齐全，但练阵时间被压缩
  2. **只补关键的**（花 5 分）→ 平衡
  3. **全部跳过** → 直接进幕 3（**练阵时间最充裕**，但残魂不全 → 代价在幕 4）
- **结果**：`flag.soul.drifting` 补齐。**若 6 世魂 + 6 游魂齐全 → `flag.soul.reforgeUnlocked = true`**。

### 幕 3 · 故人（20 分 · `quest.vol7.companions`）★ 练阵重点

- **触发**：归墟之前。
- **内容**：**同伴回归**——**但出场不长**，目的明确：**让玩家练阵法**。
  - 只有 **`flag.bond ≥ 生死之交`** 的伙伴才会来（**羁绊不够的不会出现**）。
  - **★ 核心环节：排阵、试阵、再排阵**：
    - 玩家把回归的同伴放进 **1 / 2 / 3 号位**，**试不同的阵型加成**。
    - **第六世的凡人三人**（周戍 / 孙婆婆 / 阿灰）**最适合练手**——他们"不强"，正好让玩家**把注意力放在"位置"上**。
  - **★ 一句台词（由主角说）**：
    > "你们不用帮我打赢。"
    > "**你们只要站在那儿，我就知道该怎么打了。**"
- **玩家选择项**：
  1. **认真试一遍所有阵型** → 幕 4 决战时**阵型自由切换**
  2. **随便排排** → 幕 4 只能用**一种固定阵型**
- **结果**：所有人到齐（或没到齐）。**封蚀之阵**就在下面。

### 幕 4 · 镇蚀（40 分 · `quest.vol7.quelling`）★ 本卷重心

- **触发**：下至封蚀之阵。
- **内容**：**三段式决战**：
  - **阶段 1 · 蚀痕外围（12 分）**：
    - 用**前六世的指令**轮流清场——**这是"重构术"的展示场**（任意组合，打法随玩家）。
  - **阶段 2 · 劫主（12 分）**：
    - **殷无咎**在这里等着。
    - **敌 or 友，取决于 `flag.stand.ying`**：
      | `flag.stand.ying` | 结果 |
      | --- | --- |
      | ≤ −1（坚定反驳过他） | **敌对**——必须打败他；他会说"你终于站到了**另一边**" |
      | 0 / +1 | **半敌对**——他出手，但**留了一线** |
      | ≥ +2（第五世说过"我懂你"） | **并肩**——他**替主角挡下蚀的一击**，然后说"我累了，你替我看着" |
  - **阶段 3 · 蚀的本体（16 分）**：
    - 蚀**杀不死**（它是"记忆的尽头"）——只能**镇**。
    - **★ 镇蚀的方式**：**把所有人的记忆汇成一体**（同伴的、前世的、被蚀吞者的残魂）。
    - **★ 重构术的极限**：玩家要**在有限的回合里，把"指令 + 阵型 + 残魂"组合成一次"前所未有的招"**——
      **没有标准答案**（呼应"不确定性"主题）。
- **结果**：蚀被**镇**。**但主角还站在阵上，还有最后一件事。**

### 幕 5 · 归一（20 分 · `quest.vol7.unification`）

- **内容**：**主题落点 + 终局选择**：
  - **★ 自我归一（`concept.selfUnification`）**：
    主角接纳**全部六世的自己**，一一说出他们的名字——
    > "**凌越。谢无衣。荻青。拓跋野。沈无渡。柳眠。**"
    > "我知道你们都在听。"
    > "——**这一次，我们一起。**"
  - **★ 反派的对镜**：若殷无咎活到最后，他会说：
    > "你和我的残魂一样多。"
    > "可你把他们**当人**看。"
    > "……**所以，我输了。**"
- **玩家选择项（终局三选一，`ending.*`）**：

  | 结局 | ID | 内容 | 代价 |
  | --- | --- | --- | --- |
  | **断轮** | `ending.sever` | 斩断轮回；殷无咎终于得以安息 | 所有灵魂不再转生，**包括苏昭** |
  | **续轮** | `ending.continue` | 接纳无常；主角以自身填补封印 | 主角这一次**真的死了** |
  | **折中** | `ending.balance` | 主角成为**新的"守碑人"**，替下云鹤 | 永失轮回，**成为下一个殷无咎** |

- **★ 结局文本的差异**（由 flag 决定语气）：
  - `flag.anchor.story` / `flag.vol7.reread` → **元叙事尾声**：主角"把故事讲完了"（与现实世界的《The Last RPG》形成闭环）
  - `flag.bond.suzhao` 高 → 苏昭相关**额外暖场文本**
  - `flag.prologue.erasedPartner` → 揭示**当年那个合伙人**
- **结果**：**终章**。

## 四、本章"不确定性"锚点

- 记忆回廊中**可补收的游魂随机**（但不超过漏收数）。
- 幕 4 阶段 3 中，**蚀的形态随机**（心智 / 记忆 / 存在，三种之一）——改变战斗目标表述。
- 镇蚀最终一击的**组合方式不限**——**玩家自己"拼"出来的招，就是那一招**。
