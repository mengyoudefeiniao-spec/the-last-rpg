# 提示词模板（AI 美术 · 即梦为主）

> **怎么用**：把 **① 风格锚段（固定不变）** + **② 对应章节的场景段** 拼起来，粘进即梦，比例选 **16:9**，生成后挑一张。
> 风格基准 = `jimeng-2026-09-25-6848-HD-2D.png`（剑冢雪地）。

---

## 一、风格锚段（**固定 · 所有图都用它**）

> 这一段**永远不动**——它保证 8 章看起来是**同一款游戏**。

**中文（即梦）**

```
像素风格 JRPG，HD-2D 质感：像素角色与地面，背景为高清手绘；
景深分明（近处清晰、远处朦胧）；电影感宽画幅构图；
色彩干净不脏；光线有层次（体积光 / 雾气 / 飘浮粒子）。
```

**英文（Midjourney 备用）**

```
pixel art JRPG, HD-2D style: pixel characters and ground, painterly high-res background,
distinct depth of field, cinematic wide composition, clean colors,
layered volumetric lighting, fog, floating particles
```

## 二、每章场景段（拼在风格锚段之后）

### 序章 · 现实世界（`story.prologue`）

```
深夜的出租屋，一张堆满泡面盒的电脑桌，显示器还亮着，
屏幕上是一款没做完的像素游戏；窗外是城市霓虹与雨；
室内偏暗，只有屏幕的冷光照在椅子上；孤独、安静、有点心酸。
```

### 第一世 · 青芜山下（`story.vol1`）

```
东荒边陲的小山村，青石板路与茅屋，屋后是连绵的青山与竹林；
清晨山雾未散，一条小路通向山里；远处有一座不起眼的古碑；
色调青绿与土黄，朴素、荒凉但有生气。
```

### 第二世 · 剑冢（`story.vol2`）★ 已有风格锚

```
雪原中的剑冢：无数把断裂的巨剑斜插在积雪里，剑身结霜、反着冷光；
远处是覆雪的山脊与低垂的阴云；冷蓝与霜白色调；
几缕体积光从云缝斜射下来；前景站着一个像素小人（剪影即可）。
```

### 第三世 · 天枢台（`story.vol3`）

```
悬空的巨大楼阁，穹顶是旋转的星空与无数典籍；
中央一座巨大的古碑与环绕的符阵，符文微微发光；
纸符在空中飘浮、缓慢旋转；色调暗绿与符纸黄；
神秘、逼仄、像在藏书与星辰之间。
```

### 第四世 · 万兽山（`story.vol4`）

```
辽阔的草原与翻涌的云海，远山如兽脊；
草原上有成群的灵兽剪影（狼、鹰、巨兽）；
风吹草浪，一匹白狼站在高处回头；
色调金褐与雪白，辽阔、自由、苍凉。
```

### 第五世 · 血河宗（`story.vol5`）

```
地下的血色溶洞，一条暗红的"血河"缓缓流过；
钟乳石如獠牙垂下，岩壁上刻着古老的符文，火光幽暗；
远处有一座巨大的血色祭坛；色调血红与墨黑；
压抑、危险、庄严，像一座地下的宫殿。
```

### 第六世 · 中州坊市（`story.vol6`）

```
古代城市的市井街巷，两侧是木门店铺、灯笼与幌子；
下着细雨，青石板上映着暖黄的灯光；
行人撑伞、挑担、叫卖；远处是灰蒙蒙的宫城轮廓；
色调暖黄与灰，烟火气、人味、带一点乱世的疲惫。
```

### 第七世 · 封蚀之阵（`story.vol7`）

```
幽冥深潭上方的巨型法阵，无数符文在空中缓缓旋转；
天上有一道极淡的黑色裂痕（"蚀"），向下渗出虚空；
地面站着一排同伴的背影（像素，小而坚定）；
色调幽蓝与苍白，庄严、肃穆、像世界尽头。
```

## 五、使用纪律

1. **风格锚段一个字都别改**——改了就不统一了。
2. 生成结果**必须人工过一遍**（修光影、像素化）——AI 出料，人打磨。
3. 保留了**生成日志**（提示词 / 日期 / 工具）——不发行也要留档，便于复现。
4. 这是**学习项目**，不涉及商业发行；但**别用"复刻知名 IP / 明星"**的提示词。
