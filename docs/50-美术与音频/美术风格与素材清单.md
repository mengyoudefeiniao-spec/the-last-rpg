# 美术与音频 · 风格与素材清单

> `50-美术与音频/` 的第一份文档。它规定**风格**、列出**每章需求**、给出**开源来源与授权**、并订明**目录与命名**。
> 具体逐项素材的授权登记，另见 `素材来源与授权.md`。

---

## 一、总体美术风格

- **游戏整体：像素风**（基准 **16×16 / 32×32**），保留颗粒感与手作气。
- **战斗场景背景：精致**——参考 **《八方旅人》(Octopath Traveler) 的 HD-2D**：
  - 角色与地面是**像素**；**背景层**用**高清手绘**，叠加**景深、体积光、粒子、天气**。
  - 战斗的"**舞台感**"要足：**地面、远景、光、风/雪/血雾**都要"贵"。
- **特例 · 序章**：序章里《The Last RPG》的游戏片段，用**更粗的 1-bit / 低分辨率像素**，
  与主游戏画风**刻意拉开**——**元叙事需要这层"这是另一款游戏"的区分**。

## 五、目录与命名约定

素材落在 `public/`（构建时原样拷贝）：

| 目录 | 内容 |
| --- | --- |
| `tilesets/` | 地图图块 |
| `sprites/` | 角色 / 生物 |
| `portraits/` | 对话立绘 |
| `bgm/` | 背景音乐 |
| `sfx/` | 音效 |
| `ui/` | 界面元素 |
| `fonts/` | 字体 |

**命名**：`<来源>_<类别>_<名>.<ext>`，全小写、短横线，例如 `kenney_tiles_roguelike-rpg.png`、`kenney_sfx_sword-unsheathe.ogg`。
