## 四、署名机制（CC-BY 素材）

**已接受 CC-BY**（需署名）。所有 CC-BY 素材必须**集中登记并在游戏内署名**：

- **登记**：本文件"一、已获取的起手素材"表 + 后续新增条目，必须写明**作者 / 来源 URL / 授权**。
- **署名位置**：**通关致谢**（Credits）界面 —— 列出"素材名 — 作者 — 授权 — 来源链接"。
- **CC0 素材**（如 Kenney）**不强制**，但仍建议一并列出（"Art & Sound: Kenney (kenney.nl) — CC0 1.0"）。

## 五、AI 辅助美术的注意

战斗背景（HD-2D）与立绘采用 **AI 辅助生成**，需注意：

1. **授权**：所用模型 / 服务的**商用条款**必须确认（部分工具对生成物主张权利或限制商用）。
2. **一致性**：同一场景的多张图要**锁定风格 / 色调 / 构图**，避免"每张都不一样"。
3. **"贵"的部分仍需人工修**：HD-2D 的关键在**光影与景深**——AI 出底图后需**人工叠加**光/雾/粒子。
4. **登记**：AI 生成的美术**也要登记**（来源写"AI 辅助 + 工具名"），保持可追溯。
