> **目的**：用**同一段提示词**，在几家在线服务上各出一张图，**由你判断**后续主用哪家。
> 对象场景：第二世的**剑冢**（见 `../50-美术与音频/美术风格与素材清单.md` 第三节）。

## 二、三家服务怎么操作

### A. Midjourney（Discord）

1. 注册 Discord → 加入 Midjourney 服务器 → 订阅（最低约 **$10/月**）。
2. 在任意 `#general` 频道输入 `/imagine`，粘贴**英文版提示词** + `--ar 16:9 --style raw`。
3. 等 4 张候选 → 选一张 `U1–U4` 放大 → 下载。
4. **注意**：英文提示词效果通常更好；风格偏"美术感"。

### B. 即梦（字节跳动）

1. 网页版登录（有免费额度）。
2. 选**图片生成** → 粘贴**中文版提示词**。
3. 比例选 **16:9**；模型/风格选**插画 / 像素**类（若有）。
4. 生成后下载。
5. **注意**：中文理解好，速度快；风格偏"国风/插画"。

### C. 通义万相（阿里）

1. 网页版登录（有免费额度），或走**阿里云 DashScope API**。
2. 粘贴**中文版提示词**，比例 **16:9**。
3. 生成后下载。
4. **注意**：有**正式 API**——**如果愿意给 API Key，可以脚本化批量出图**（见第五节）。

## 五、可选的"脚本化"路径（需 API Key）

**通义万相（DashScope）有正式 API**。如果你给出 API Key，可以这样做（示意，**不要**把 key 写进仓库）：

```powershell
# 示意：调用通义万相文生图并保存
$key = $env:DASHSCOPE_API_KEY
$body = @{ model = 'wanx-v1'; input = @{ prompt = (Get-Content '剑冢雪地-提示词.txt' -Raw) }; parameters = @{ size = '1280*720'; n = 1 } } | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri 'https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis' `
  -Method Post -Headers @{ Authorization = "Bearer $key"; 'X-DashScope-Async' = 'enable' } `
  -ContentType 'application/json' -Body $body
# 拿到 task_id 后轮询查询结果，再下载图片 URL
```

### ⚠️ 商用授权（重要 · 必须在发行前解决）

即梦 **C 端用户协议**要点：

- 平台授予用户的许可为"**个人的、可撤销的、不可转让的、非独占的和非商业的**"；
- 明确禁止"授权范围之外的任何形式的**销售和商业使用**"；
- 生成内容的权利"**在法律法规允许的范围内**"归用户，但平台保留自身 IP 与广泛使用权；
- **纯 AI 生成、无人类创造性投入的内容，可能不受著作权保护**。

**结论**：**确认之前，本图只作"风格锚"，不进正式发行版本。**

**确认路径（三选一）**：

1. 购买**付费会员**，核对会员权益页是否含"**商用授权**"，并保存《内容授权书》等凭证；
2. 改用**火山引擎 API 版**（协议明文允许合规商用，但**风险自担**）；
3. 改用条款更明确的服务（如 Adobe Firefly 等）。

**降风险动作**：

- **保留完整生成日志**（提示词 / 模型版本 / 时间 / 种子）；
- **人工二次创作**（强化"人类贡献"，也让图更可用）；
- **不要**用"复刻知名 IP / 明星肖像"的提示词；
- 发行时履行 **AI 生成内容标识**义务。
