# 20260925 · 每世专精指令（替换"现代思维型选项"）

## 背景

前两版把"每世 +1 个可操作选项"设计为"现代思维型"的小能力（预设 / 抢拍 / 拆解 / 找漏 / 延后 / 倾听）。
复查后确认这个设计与**代码里的战斗指令体系**脱节：
`src/shared/systems/battle/commands.ts` 里玩家真正能按的按钮是
**普通攻击 / 法术 / 特技 / 法宝 / 灵宝 / 召唤 / 捕捉 / 防御 / 逃跑**（九条 `CommandId`），
而"预设 / 抢拍……"在战斗里**无处安放**。

要求：**每世 +1 个可操作选项，名称与剧情对应，形成专精**——
例如第一世只会普攻、后学「法术」；第二世学「特技」「灵宝」但**不会法术**；第七世把所有选项灵活应用。

## 备选项

### A. 选项的形态
1. 保留"现代思维型"选项（与战斗指令并存）。
2. **改用战斗指令专精**（对齐代码 `CommandId`）。

### B. 跨世继承
1. **继承**（学会就永久保有）。
2. **不继承**（每世由出身 / 体系决定），**第七世因集齐残魂而全部回归**。

## 决定

| 项 | 决定 |
| --- | --- |
| A | **战斗指令专精**（选项 2） |
| B | **不继承**（选项 2）——单世专精、第七世全开 |
| `talisman` 中文 | 由"符箓"**修正为「法宝」**（与代码 label 一致）；符箓是法宝的一类 |
| 战斗外系统 | 新增 **「炼魂」**（第 5 世 · **召唤兽合成**）、**「阵法调整」**（第 6 世 · **战前阵容 / 站位**）——**二者都不是战斗内指令**，代码侧待定 |

### 为什么"不继承"

1. **叙事**：每世是新的肉身、新的体系——"重新学做人"。
2. **手感**：每世换一套打法，避免七世同质。
3. **回报**：**第七世的"全开"因此才珍贵**——它对应"接纳所有世代的自己"（自我归一）。
4. **主题**：**反派压制残魂（不用其能力），主角接纳残魂（能力全部回归）。**

## 后果

### 直接收益
- 剧本与代码**对齐**：文档里的指令名 = 代码 label，将来导出 `data/` 无需语义转换。
- 每世有明确的"手感差异"，学习曲线变成**七段不同体验**。
- 第七世"全部指令自由组合"成为**机制与主题的双重高潮**。

### 需要承担的约束
- 「预设 / 抢拍 / 拆解 / 找漏 / 延后 / 倾听」**全部移除**；术语 `concept.actionOption` → `concept.specialty`。
- **术语表第三节**修正：`talisman` = **法宝**（原误写为"符箓"）。
- 新增两条**战斗外系统**（炼魂＝召唤兽合成 / 阵法调整＝战前阵容站位）。它们**不是 `CommandId`**，
  代码侧应落在**养成与战前准备**模块（召唤兽实体、合成逻辑、阵容配置），**待与实现对齐**。
- 第一卷新增"**负向指令教学**"（第一幕只有普攻）+ "**每世打法不同**"的过场预告。
- Canon 铁律第 6、7 条改写为"单世专精、互不继承""第七世全开"。
