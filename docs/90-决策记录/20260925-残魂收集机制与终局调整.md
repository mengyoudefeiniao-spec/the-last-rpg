# 20260925 · 残魂收集机制与终局调整

> ⚠️ **本记录的部分内容已被取代**：残魂已细分为「世魂 ×6 + 游魂 ×6」。
> 后续变更以 `20260925-残魂双类与自我归一.md`、`20260925-每世专精指令.md` 为准。

## 背景

第一版剧本（同日 `20260925-世界观基调与轮回机制.md`）确立了「世代转世」。
但复查后发现一个**结构性问题**：七世之间只有苏昭、云鹤、殷无咎三个跨世角色作为连接，**每一世与主角的联系依然单薄**——
玩家打完一世，除了"又死了一次"，缺少能**累积、能回报**的东西。

同时，原「残章」设定把前世记忆当作**被动**的线索（会衰减、会污染），
它与"成长"是脱节的：主角收集到再多记忆，也不改变他能做什么。

据此提出四点修改要求：

1. 把「残章」更名为「**残魂**」；
2. 用**收集残魂**把七世剧情串联起来，拼出完整故事线；
3. 主角时常冒出与异世界**不匹配的现代词汇 / 记忆碎片**（错位感）；
4. 集齐残魂后**恢复现代记忆**，并**用现代知识重构术法与武技**，最终**与同伴一起战胜「蚀」**。

## 备选项

### A. 残魂与主线的关系
1. 残魂仅作"额外收集品"，不影响主线。
2. **残魂是主线硬连接**：每世归位一枚「世魂」，集齐 = 拼出完整故事线、恢复现代记忆，并解锁最终战斗手段。

### B. 结局处理
1. 用"战胜蚀"**取代**原三选一结局。
2. **保留三选一，但重新定位为「战后尾声」**：战胜蚀是确定的高潮，轮回归宿是玩家的选择。

### C. ID 命名
1. 沿用旧 ID（`reincarnation.fragment`），只改中文名。
2. **ID 一并改为 `reincarnation.soulFragment`**（此时尚无 `data/` 存档与脚本依赖，改名成本最低）。

## 决定

| 项 | 决定 |
| --- | --- |
| A | **残魂是主线硬连接**（选项 2）。设「世魂 ×7 + 游魂不限」双层结构 |
| B | **保留三选一，重新定位为尾声**（选项 2）。「镇蚀」为主线高潮，**确定发生** |
| C | **ID 改为 `reincarnation.soulFragment`**（选项 2）；相关术语一并登记 |

### 关键设计

- **世魂**（`reincarnation.worldSoul`）×7：每世临终归位一枚，记录该世最重要的事 → **七世之间唯一的硬连接**。
- **游魂**（`reincarnation.driftingSoul`）：散落碎屑，三个来源（自身残留 / 蚀痕之地 / 他人所赠），长在随机事件里。
- **错位词**（`concept.misplacedWord`）：主角冒出异世界不存在的现代词，是残魂归位的信号，也是**重构术的语言基础**。
- **重构术**（`art.reforge`）：第七世恢复完整现代记忆后，用现代知识重解术法武技（能量守恒→灵气循环、编程→符箓、系统架构→封印、游戏设计→战斗）；招式超出体系解释范围，**有反噬代价**。
- **镇蚀**（`concept.quelling`）：与同伴合力战胜蚀；同伴来自前六世结缘者的回归。

## 后果

### 直接收益
- 七世有了**唯一的硬连接**（世魂），每世都必须写清"归位了哪枚、想起了什么"。
- 成长轴从"被动记忆"变为"**主动收集 + 最终兑现（重构术）**"，与"战胜蚀"闭环。
- 「错位词」成为本作**标志性的气氛与演出**，同时自然地解释了"穿越者"的孤独。
- 与《The Last RPG》的**元叙事**（游戏开发者用游戏设计思维解构战斗）正式咬合。

### 需要承担的约束
- **Canon 铁律由 6 条扩为 8 条**（新增"残魂需集""错位"，改写"重构与镇蚀""尾声三选一"）。
- 每一卷的详案都必须新增"残魂"小节（世魂记录 / 归位点 / 现代记忆 / 错位词）。
- 重构术在代码侧**尚无对应 `CommandId`**，暂记为"待定"（见 `../10-世界/规则体系.md` 第七节）。
- 「残章」一词从全项目移除；若后续文档仍出现该词，**按错误处理**。
