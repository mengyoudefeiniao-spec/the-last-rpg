## ⚠️ 风险：商用授权未确认

查阅即梦 **C 端用户协议**后确认：

- 授予用户的许可为"**个人的、可撤销的、不可转让的、非独占的和非商业的**"；
- 明确禁止"授权范围之外的任何形式的**销售和商业使用**"；
- 生成内容权利"**在法律允许的范围内**"归用户，但平台保留自身 IP 与广泛使用权；
- **纯 AI 生成、无人类创造性投入的内容，可能不受著作权保护**。

> **本项目为本地学习项目、不对外发行**，故此项**不构成障碍**；若将来转为发行，需重新确认商用授权。

**确认路径**：① 付费会员权益（索取《内容授权书》）；② 改用火山引擎 API 版（合规商用、风险自担）；③ 改用条款更明确的服务。

**降风险**：保留生成日志（提示词 / 模型版本 / 时间 / 种子）、人工二次创作、避免复刻知名 IP、发行时做 AI 内容标识。
