# 20260925 · 平衡参数与素材策略

## 背景

三项要求：

1. **BGM 接受署名**（即接受 CC-BY，需在游戏内署名）；
2. **战斗背景用 AI 辅助生成**（HD-2D 是本作最贵的美术项）；
3. 把**战斗与成长落成可调参数**，供实现轨道取用。

## 决定

| 项 | 决定 |
| --- | --- |
| BGM 授权 | **接受 CC-BY（须署名）** → 建立**署名机制**（登记 + 通关致谢） |
| HD-2D 战斗背景 | **AI 辅助生成** + **人工修光影**（AI 出底图，人工叠加光/雾/粒子） |
| 参数落点 | 新建 `../40-玩法设计/战斗与成长.md`，**只建议参数**；实际写入 `src/shared/config/balance.ts` 由**实现轨道**决定 |

### 参数覆盖范围（新增部分）

| 类别 | 关键参数 |
| --- | --- |
| **指令** | `commandCost`（MP/SP）、`commandPower`（威力基准）、`spiritTreasureMaxPerBattle` |
| **九境成长** | `realmCapByGeneration` —— **每世境界上限不同**（第六世为 0） |
| **残魂** | `soul`（6 / 6）、`soulSkill`（游魂六技能参数） |
| **炼魂** | `soulRefining`（`maxRarity`、`maxLevel`、`levelAverageFactor`） |
| **阵法** | `formation.slotBonus`（1 输出 / 2 治疗 / 3 速度） |
| **羁绊** | `bond.lifelongThreshold = 4`、`kindredThreshold = 5`、`maxGainPerGeneration` |
| **镇蚀** | `quelling`（三阶段、同伴协同加成、`phase3TurnLimit`） |
| **随机事件** | `randomEvents`（冷却、蚀痕倍率、种子入存档） |

### 素材策略（三层）

1. **CC0 起步**：Kenney（图集 / UI / 音效 / 字体）——已获取。
2. **CC-BY 补充**：BGM（Incompetech 等）——**必须署名**。
3. **AI 辅助**：HD-2D 战斗背景、立绘——需确认工具商用条款，**且仍要登记**。

## 后果

### 直接收益
- `balance.ts` 有了一份**明确的扩展清单**（本次**未改代码**，只在文档里给出建议的常量结构）。
- 素材授权链路清楚：**登记 → 署名 → 可追溯**。
- "每世从零、第七世全开"有了**数值表达**（`realmCapByGeneration`）。

### 需要承担的约束
- **AI 生成物也要登记**（来源写"AI 辅助 + 工具名"）。
- CC-BY 素材**必须**在通关致谢中署名，否则授权不成立。
- 参数为**首版估算**，需**实测校准**。
