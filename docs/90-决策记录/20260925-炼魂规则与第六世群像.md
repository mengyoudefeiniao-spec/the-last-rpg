# 20260925 · 炼魂合成规则与第六世群像

## 背景

细化要求（含后续修订）：

1. **炼魂确认归第五世**（魔道）；
2. **阵型也每世重置**；第六世增补**凡人队友**——体现"苦难中人性善良面的互助"，并作**阵法加成的教学**；
3. **炼魂要有一套合成规则**，但**游戏内不提示**，玩家自己合出来才**解锁图鉴**；
4. **（修订）** 规则要**简单**——按**稀有度 + 等级**两条；**先不做成就系统**；第七世队友**出场不长**、主要为**练习阵法**；召唤兽数据**独立放置**。

## 决定

| 项 | 决定 |
| --- | --- |
| 炼魂归属 | **第五世**（血河宗魔道） |
| 维度 | **稀有度**（`rarity`）+ **等级**（`level`）——只有两个 |
| 合成规则 | **稀有度**：同稀有度 → **+1**（`3+3 → 4`）；不同 → **取较高者**（`1+3 → 3`）。**等级**：**两只材料的平均等级** |
| 玩法态度 | **不给公式**；试出来的组合才点亮图鉴（`bestiary`）；**合成不可逆**；**暂不做成就系统** |
| 阵型继承 | **每世重置**（第七世随重构术回归） |
| 第六世队友 | **周戍**（1 号位 · 输出）· **孙婆婆**（2 号位 · 治疗）· **阿灰**（3 号位 · 速度） |
| 第七世队友 | **出场不长**，主要让玩家**练习"阵法调整"**（阵型此时才随重构术回归，需练手） |
| 召唤兽数据 | **独立目录 `data/creatures/`**（便于以后扩展） |

### 合成示例（规则就这两条）

| 材料 A | 材料 B | 产出稀有度 | 产出等级 |
| --- | --- | --- | --- |
| 3 · Lv10 | 3 · Lv20 | **4** | 15 |
| 1 · Lv10 | 3 · Lv20 | **3**（不变） | 15 |
| 5 · Lv30 | 5 · Lv30 | **6** | 30 |

> 玩家要自己摸出"**只有同稀有度才 +1**"这条。

### 第六世群像

三个凡人，三种"善良"：**受过苦还护人的老兵**、**救人不问贵贱的草药婆**、**乱世里还笑的少年**。
- **教学**：阵法调整——玩家**亲手把他们放对位置**。
- **主题**：把"羁绊"从修士扩展到**凡人**——**他们只活这一世**。

## 后果

### 直接收益
- `40-玩法设计/` 首次有内容（此前为空）。
- 阵法调整有了**明确的教具**与情感载体。
- 炼魂从"一句话设定"变成**可探索的收集玩法**，且规则**足够简单**（两条），易于实现。

### 需要承担的约束
- 术语表新增 `creature` / `bestiary`；人物表新增 3 名 NPC。

- **合成公式绝不进面向玩家的界面**（任务 / 提示 / 图鉴说明）。
- 三名凡人队友在第七世**出场不长**，**目的明确：让玩家练阵**。
- **不做成就系统**：图鉴只"点亮"，不加奖励弹窗。
