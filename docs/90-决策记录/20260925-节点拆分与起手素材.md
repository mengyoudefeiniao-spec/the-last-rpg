# 20260925 · 任务节点拆分与起手素材

## 背景

三项要求：

1. **时长校准暂缓**（结合后续开发效果再调）；
2. 美术风格定为**整体像素风 + 战斗背景精致**（参考《八方旅人》**HD-2D**），并按每章特点**补充美术与音频素材**（可从开源免费站获取）；
3. 各章详案要**拆出任务 / 对话节点**。

## 决定

### A. 节点拆分

8 份详案（序章 + 七世）各新增一节 **「任务与对话节点拆分」**：

- **任务节点**：`quest.<章>.<短横线名>`，含"触发 / 目标 / 结果 + flag"。
- **对话节点**：`dlg.<章>.<短横线名>`，节点 `n_<短名>`，含"说话人 / 内容 / 效果"。
- 各卷末尾的"待定"节顺延为 **第七节**。

### B. 美术风格

| 层 | 风格 |
| --- | --- |
| 游戏整体 | **像素风**（16×16 / 32×32 基准） |
| **战斗场景背景** | **精致**（**HD-2D**：像素角色 + 高清手绘背景 + 景深 / 体积光 / 天气） |
| 序章的游戏片段 | **1-bit 粗像素**（与主游戏**刻意拉开**，服务元叙事） |

### C. 起手素材（实际获取）

全部来自 **Kenney**（**CC0 1.0**），经其镜像 `ETdoFresh/kenney.nl` 获取，落在 `public/`：

| 类别 | 数量 | 路径 |
| --- | --- | --- |
| Roguelike/RPG 图集 | 1 | `public/tilesets/` |
| Roguelike Cave 图集 | 2 | `public/tilesets/` |
| Pixel UI 图集 | 2 | `public/ui/` |
| **RPG 音效** | **51** | `public/sfx/` |
| 像素字体 | 11 | `public/fonts/` |

### D. 授权登记制度

新建 `../50-美术与音频/素材来源与授权.md`：**任何外部素材必须先登记**；
CC0 免署名（仍建议致谢），**CC-BY 必须署名**。

## 后果

### 直接收益
- 每章详案现在**可直接落到 `data/quests/` 与 `data/dialogues/`**（节点表已给出）。
- 项目**立刻有了可跑原型的素材**（图块、UI、音效、字体俱全）。
- 风格有了**明确基准**（像素 + HD-2D 战斗）。

### 需要承担的约束
- **尚缺**：BGM（8 章）、**HD-2D 战斗背景**（最贵项）、角色立绘、中文字体（商用许可）。
- 素材**只放 `public/`**，不手工拷到 `dist/`（构建流程负责）。
- 新增的 `quest.*` / `dlg.*` 节点若跨文件引用，须与详案保持一致。

### 涉及文件
- **新建**：`../50-美术与音频/美术风格与素材清单.md`、`../50-美术与音频/素材来源与授权.md`；`public/` 下素材若干
- **修改**：8 份主线详案（各加"任务与对话节点拆分"）、`../00-总览/术语表.md`
