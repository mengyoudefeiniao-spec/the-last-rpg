# 时间线（Timeline）

> 纪年：**大衍历**。以主角穿越之年为 **元年（0 年）**，之前记负年。
> 主角灵魂跨越约 **四百年**、转生 **七世**。每世之间有一段「界间漂流」。
>
> **主线动线**：主角的现代记忆碎成 **6 枚「世魂」**（对应**前六世**），每世临终归位一枚；
> 另有 **6 枚「游魂」**散落在**世界各处的隐藏区域**（各解锁一项专属技能）。
> **每世的战斗指令由该世体系决定（互不继承）**；集齐残魂后，第七世**全部指令回归** = **重构术**（见 `../10-世界/规则体系.md` 第六、七节）。

## 五、写作约束

1. 每世的**纪年跨度不超过 50 年**，世与世之间留 30–50 年的"界间漂流"与时代变迁。
2. **殷无咎、云鹤、苏昭**是跨世角色，其在各世的身份需与 `../20-人物/` 档案一一对应。
3. 任何新事件加入时间线时，**必须同步更新 `../00-总览/术语表.md` 与本表**。
4. **每世必须写明**：该世专精指令、归位了哪枚世魂、本世游魂藏在何处、与谁结下多深的**羁绊**。
