> **本作另有两条"体系外"机制**——它们**都不是战斗内指令**，而是**战斗外的系统**（代码侧暂无，见 `../10-世界/规则体系.md` 第 7.2 节）：
> **炼魂**（`art.soul-refining`）＝**召唤兽合成**；**阵法调整**（`art.formation-control`）＝**战前阵容 / 站位配置**（**每世重置**）。
>
> **炼魂配套**（见 `../40-玩法设计/炼魂合成规则.md`）：
> **召唤兽**（`creature`）＝可被捕捉 / 合成 / 召唤的兽，只有**稀有度**与**等级**两个维度；数据**独立放 `data/creatures/`**（便于以后扩展）；
> **图鉴**（`bestiary`）＝玩家**自己合成过**才点亮的收集册（未合成显示"？？？"）。
> 已登记的召唤兽：**雪狼·巴音**（`creature.bayin`）——第四世的契约灵兽，第七世可被召唤。

### 4.2 残魂（本作核心收集机制）

**残魂**（`reincarnation.soulFragment`）是主角灵魂中残留的、来自现实世界的碎片。分**两类**，用途完全不同。

#### 4.2.1 世魂 —— 解锁记忆（主线）

| 中文 | ID | 说明 |
| --- | --- | --- |
| 世魂 | `reincarnation.worldSoul` | 共 **6 枚**（对应**前六世**）：每世临终归位一枚，记录该世最重要的事与**该世掌握的指令**。归位即**解锁一段现代记忆**；**六枚集齐 = 第七世全部指令回归**。主线必然归位，不会漏 |

#### 4.2.2 游魂 —— 解锁专属技能（探索）

| 中文 | ID | 说明 |
| --- | --- | --- |
| 游魂 | `reincarnation.driftingSoul` | 共 **6 枚**：藏于**世界各处的隐藏区域**，需探索发现。每枚解锁一项**专属技能**（对应一个现代词汇）。**可以漏掉** |

#### 4.2.3 与残魂相关的机制

| 中文 | ID | 说明 |
| --- | --- | --- |
| 错位词 | `concept.misplacedWord` | 主角不受控冒出的**现代词汇**。异世界无对应概念，是**残魂临近的信号** |
| 专精（指令 / 系统） | `concept.specialty` | 每世因**出身 / 体系**而拥有的**战斗指令**与**战斗外系统**（**各不相同，互不继承**）；第七世集齐残魂后**全部回归**。见 `../10-世界/规则体系.md` 第七节 |
| 专属技能 | `skill.soulSkill` | 每枚**游魂**解锁的技能（编译符 / 循环阵 / 缓存体 / 并行诀 / 契灵协议 / 分支诀） |
| 重构术 | `art.reforge` | **不是技能，而是"全部指令同时可用、自由组合"**。第七世决战、集齐全部残魂时达成 |
| 自我归一 | `concept.selfUnification` | 终极目标：接纳所有世代的自己是"同一个我"，**与自己和解** |
| 残魂三律 | `rule.soulFragmentRules` | **碎片化 / 会错位 / 会污染**（见 `../10-世界/规则体系.md`） |

> **改名记录**：原「残章」（`reincarnation.fragment`）已更名为**残魂**（`reincarnation.soulFragment`）。
> 理由与后果见 `../90-决策记录/20260925-残魂收集机制与终局调整.md`、`../90-决策记录/20260925-残魂双类与自我归一.md`。
