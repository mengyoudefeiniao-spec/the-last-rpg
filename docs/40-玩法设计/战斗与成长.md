# 战斗与成长 · 可调参数

> **唯一落点**：所有数值最终只进 `src/shared/config/balance.ts`（`BALANCE` 常量），**不散落进各系统**（见 `src/README.md`）。
> 本文件给出**参数名 / 默认值 / 作用 / 归属**，实现时照抄即可。

---

## 一、设计原则

1. **数值集中**：只改 `BALANCE`，别写死在系统里。
2. **首版给"能跑"的默认值**，不追求精确平衡——**先让它动起来**。
3. **成长不是数值继承**：跨世成长靠**残魂 / 羁绊 / 指令回归**，不是"等级带过去"（见 `../10-世界/规则体系.md` 第七节）。
4. **每世从零**：单世数值重新生长，**第七世**才把一切合起来。

---

## 二、现有参数（`BALANCE`，保留不动）

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `damageVariance` | 0.1 | 伤害随机浮动 ±10% |
| `minDamage` | 1 | 伤害下限 |
| `critChance` / `critMultiplier` | 0.1 / 1.5 | 暴击率与倍率（仅物理与特技） |
| `defendReduction` / `defendSpReward` | 0.5 / 10 | 防御减伤与回 SP |
| `defFactor` / `resFactor` | 0.6 / 0.6 | 物防 / 法抗抵消系数 |
| `spGainPerDamageTaken` | 0.6 | 受击获得 SP |
| `spRegenPerTurn` / `mpRegenPerTurn` | 6 / 3 | 每回合自然回复 |
| `fleeBaseChance` / `fleeSpdFactor` / `fleeFailSpReward` | 0.45 / 0.03 / 12 | 逃跑 |
| `captureBaseChance` / `captureHpWeight` | 0.15 / 0.6 | 捕捉 |
| `aiSkillHpThreshold` | 0.5 | 敌人 AI 用特技的血量阈值 |

## 三、指令参数（新增 · `commandCost` / `commandPower`）

| 指令 | MP | SP | 威力基准 | 备注 |
| --- | --- | --- | --- | --- |
| `attack` | 0 | 0 | `atk × 1.0` | **命中/受击回 SP**（已有机制） |
| `spell` | **8** | 0 | `mag × 1.4` | 吃 `res` |
| `skill` | 0 | **20** | `atk × 1.8` | 吃 `def`，**可暴击** |
| `talisman` | **5** | 0 | `mag × 1.2`（一次性） | 可叠短时增益 |
| `spiritTreasure` | **12** | **15** | `mag × 2.2` | 高阶；**每战次数受限** |
| `summon` | **10** | 0 | 视兽而定 | 契约兽在场时可用 |
| `capture` | 0 | 0 | — | 走 `captureBaseChance` |
| `defend` | 0 | 0 | — | 已有 |
| `flee` | 0 | 0 | — | 已有 |

```ts
/** 指令的资源消耗。 */
commandCost: {
  spell: { mp: 8 }, skill: { sp: 20 }, talisman: { mp: 5 },
  spiritTreasure: { mp: 12, sp: 15 }, summon: { mp: 10 },
},
/** 指令的威力基准（对 atk / mag 的倍率）。 */
commandPower: {
  attack: 1.0, spell: 1.4, skill: 1.8, talisman: 1.2, spiritTreasure: 2.2,
},
/** 每场战斗中，灵宝最多使用次数（防止一招打穿）。 */
spiritTreasureMaxPerBattle: 2,
```

## 四、九境成长曲线（新增 · `realmCapByGeneration`）

**每世有境界上限**——这是"每世从零、且上限不同"的数值化。

| 世 | 体系 | 境界上限 | 说明 |
| --- | --- | --- | --- |
| 1 | 凡骨 → 引灵 | **引灵后期** | 凡骨，最惨 |
| 2 | 太玄剑宗 | **金丹** | 上等灵根，爽 |
| 3 | 清源观 | **金丹** | 中等灵根 |
| 4 | 万兽山 | **凝罡** | 靠兽，不靠境界 |
| 5 | 血河宗 | **元婴** | 魔道资源多 |
| 6 | 凡人 | **无**（0） | 完全没有修为 |
| 7 | 集齐残魂 | **化神** | 集六世之力 |

```ts
/** 九境序号：引灵1 凝罡2 筑基3 金丹4 元婴5 化神6 洞虚7 合道8 渡劫9。 */
realmCapByGeneration: [1, 4, 4, 2, 5, 0, 6],
```

> **注意**：第六世为 `0`——**没有任何修为**。这一世的"战斗"全靠**阵法调整**与人。

## 五、残魂参数（新增 · `soul`）

### 5.1 数量（固定）

```ts
soul: {
  worldSoulCount: 6,   // 世魂，主线必得
  driftingSoulCount: 6, // 游魂，隐藏区域可漏
  reforgeRequires: { worldSouls: 6, driftingSouls: 6 }, // 重构术前置
},
```

### 5.2 游魂专属技能参数

| 技能 | 参数 | 默认 | 作用 |
| --- | --- | --- | --- |
| 「缓存体」 | `cacheRatio` | 0.5 | 暂存**伤害/术法**的 50%，稍后释放 |
| 「循环阵」 | `loopMaxRepeat` | 3 | 自动重复最多 3 次 |
| 「编译符」 | `compileMaxFuse` | 3 | 最多 3 张符合为一次 |
| 「并行诀」 | `parallelMaxSegments` | 2 | 同时执行最多 2 段 |
| 「契灵协议」 | `protocolDuration` | 5 | 临时共斗契约持续 5 回合 |
| 「分支诀」 | `branchMaxPlans` | 2 | 一次行动分岔出 2 个预备方案 |

```ts
soulSkill: {
  cacheRatio: 0.5, loopMaxRepeat: 3, compileMaxFuse: 3,
  parallelMaxSegments: 2, protocolDuration: 5, branchMaxPlans: 2,
},
```

## 六、炼魂参数（新增 · `soulRefining`）

合成规则见 `炼魂合成规则.md`（**稀有度 + 等级**两条）。可调项：

```ts
soulRefining: {
  maxRarity: 6,        // 稀有度上限
  maxLevel: 60,        // 等级上限
  /** 合成后等级 = 两材料平均，再乘该系数（1.0 = 原样平均）。 */
  levelAverageFactor: 1.0,
  /** 每次合成消耗的材料数（固定 2）。 */
  materialsPerFuse: 2,
  /** 图鉴解锁标记是否写存档。 */
  bestiaryInSave: true,
},
```

> **不给玩家看公式**（见 `炼魂合成规则.md`）；这些参数只存在于系统与 `BALANCE` 里。

## 七、阵法参数（新增 · `formation`）

| 号位 | 偏向 | 默认加成 |
| --- | --- | --- |
| **1 号位** | 输出 | `atk / mag +20%` |
| **2 号位** | 治疗 | 回复量 `+25%` |
| **3 号位** | 速度 | `spd +30%`（**决定出手先后**） |

```ts
formation: {
  slotBonus: {
    1: { atk: 0.20, mag: 0.20 },
    2: { heal: 0.25 },
    3: { spd: 0.30 },
  },
  /** 每世重置（第六世解锁，第七世随重构术回归）。 */
  resetsEachGeneration: true,
},
```

## 八、羁绊参数（新增 · `bond`）

| 值 | 语义 |
| --- | --- |
| 0 | 陌路 |
| 1–2 | 相识 |
| 3 | 朋友 |
| **4** | **生死之交**（镇蚀**响应门槛**） |
| **5** | **知己**（额外演出） |

```ts
bond: {
  lifelongThreshold: 4, // 生死之交 → 镇蚀时响应
  kindredThreshold: 5,  // 知己 → 额外演出
  maxPerCharacter: 5,
  /** 单世内，每名角色最多获得的羁绊点数（防"刷"）。 */
  maxGainPerGeneration: 3,
},
```

> **羁绊只在有代价的关键抉择中增长**，不能靠重复对话刷（见 `../10-世界/规则体系.md` 第八节）。

## 九、镇蚀决战参数（新增 · `quelling`）

| 阶段 | 内容 | 默认 |
| --- | --- | --- |
| 阶段 1 · 蚀痕外围 | 清场 | 3 波 |
| 阶段 2 · 劫主 | 殷无咎（敌 / 半敌 / 并肩） | 由 `flag.stand.ying` 决定 |
| 阶段 3 · 蚀的本体 | **无标准答案的组合** | 回合上限 8 |

```ts
quelling: {
  phase1Waves: 3,
  phase3TurnLimit: 8,
  /** 每名"生死之交"同伴提供的协同加成。 */
  allyBonusPerLifelong: 0.08,
  /** 每名"知己"同伴的额外加成。 */
  allyBonusPerKindred: 0.15,
  /** 残魂齐全对重构术的威力加成。 */
  reforgeFullBonus: 0.3,
},
```

> **平衡原则**：镇蚀**必然获胜**（Canon 铁律 7）——这些参数只调**难度与演出**，不调"能否赢"。

## 十一、与 `balance.ts` 的映射

把以上各节**合并进同一个 `BALANCE` 对象**（保持 `as const`）：

```ts
export const BALANCE = {
  // ……现有参数（第二节）保持不动……
  commandCost: { /* 第三节 */ },
  commandPower: { /* 第三节 */ },
  spiritTreasureMaxPerBattle: 2,
  realmCapByGeneration: [1, 4, 4, 2, 5, 0, 6],
  soul: { worldSoulCount: 6, driftingSoulCount: 6, reforgeRequires: { worldSouls: 6, driftingSouls: 6 } },
  soulSkill: { cacheRatio: 0.5, loopMaxRepeat: 3, compileMaxFuse: 3, parallelMaxSegments: 2, protocolDuration: 5, branchMaxPlans: 2 },
  soulRefining: { maxRarity: 6, maxLevel: 60, levelAverageFactor: 1.0, materialsPerFuse: 2, bestiaryInSave: true },
  formation: { slotBonus: { 1: { atk: 0.2, mag: 0.2 }, 2: { heal: 0.25 }, 3: { spd: 0.3 } }, resetsEachGeneration: true },
  bond: { lifelongThreshold: 4, kindredThreshold: 5, maxPerCharacter: 5, maxGainPerGeneration: 3 },
  quelling: { phase1Waves: 3, phase3TurnLimit: 8, allyBonusPerLifelong: 0.08, allyBonusPerKindred: 0.15, reforgeFullBonus: 0.3 },
  randomEvents: { minCooldownDays: 1, anomalyWeightMultiplierOnEclipse: 2.0, seedInSave: true },
} as const;
```

> **改代码与否**：本文件只**建议**参数，**当前不写入** `balance.ts`。
> **定位**：作为**概念与测算方法**使用；**第一版只要"大体能跑"**，不需要细致平衡（校准见 `时长与数值校准表.md`）。
