# 交互与 UI 设计

> **对齐代码**：`src/client/ui/`（界面）、`src/shared/systems/battle/`（状态机与指令）、`src/client/render/`（绘制）。
> 本文件只定**交互与信息结构**，不定像素细节。

---

## 一、总体原则

1. **一眼可读**：像素风字号有限，**信息密度要低**，关键状态（HP/MP/SP、轮到谁、状态）必须一眼看到。
2. **"每世换一套"要看得见**：指令盘随世变化——**玩家要能立刻感到"这一世我多了/少了一个动作"**。
3. **错位词是演出**：主角冒出前世的词时，要有**独特的视觉提示**（见第六节）。
4. **多输入**：先做**键鼠**，手柄/触屏留接口（`src/client/input/`）。

## 二、战斗界面

### 2.1 布局

```
┌──────────────────────────────────────────────┐
│  敌方阵列（左→右，按 spd 决定出手序）           │
│                                              │
│        ★ 战斗背景（HD-2D，本作最"贵"处）        │
│                                              │
│  我方阵列（1/2/3 号位，第六世起可调整）           │
├──────────────────────────────────────────────┤
│  指令盘                                       │
└──────────────────────────────────────────────┘
   侧栏（可收起）：战斗日志（按 LogKind 上色）
```

### 2.2 指令盘（核心）

- 展示**本世可用**的指令（见 `../10-世界/规则体系.md` 7.2）。
- **不可用的指令**：**不显示**（而不是灰掉）——因为"这一世我**没有**它"本身就是要传达的信息。
- **战斗外系统的入口**：第五世（炼魂）、第六世（阵法调整）在**战前**（不是战中）打开。

```
▶ 普通攻击   法术   特技   法宝   灵宝   召唤   捕捉   防御   逃跑
   （第五世只会亮起：普通攻击 · 法术 · 防御 · 逃跑）
```

### 2.3 阶段提示

战斗状态机（`turnStart → commandInput → statusSettlement → executeCommands → bothSidesAction → actionEnd`）
每个阶段都要有**节奏感**：

- **turnStart**：镜头轻推 + "第 N 回合"淡入。
- **commandInput**：指令盘亮起。
- **executeCommands / bothSidesAction**：按 `spd` 依次演出（**谁快谁先动**，要有"抢先手"的爽感）。

## 三、阵法调整界面（第六世解锁）

- **战前**打开；三个号位可**拖动交换**。
- 每个号位**实时显示加成**（如"1 号位：输出 +20%"）。
- **教学**：第六世第一次打开时，不弹教程，而是**让玩家自己拖**，战后由三名凡人队友"说"出效果（见 `../30-剧情/主线/第六卷-凡尘一梦.md`）。
- **每世重置**：第七世才回来（随重构术）。

---

## 四、图鉴界面（第五世解锁）

- **未合成过的条目显示 `？？？`**（连名字都不给）。
- 合成过 → 点亮，显示名字 / 稀有度 / 等级 / "怎么来的"。
- **不给公式**（见 `../40-玩法设计/炼魂合成规则.md`）。
- **暂不做成就系统**。

---

## 五、残魂界面

| 区 | 内容 |
| --- | --- |
| **世魂（6）** | 已归位 ①–⑥；每枚显示"记录的那件事" |
| **游魂（6）** | 已拾得 / 未拾得（未拾得显示所在**世**，不显示具体位置） |

- **集齐提示**：6 + 6 齐全时，出现一次**重构术达成**的演出（第七世）。
- **不显示坐标**：给**线索**，不给地图标记（保持探索感）。

---

## 六、对话界面（**错位词**的演出）

- **常规**：立绘 + 文本框 + 选项（格式见 `../30-剧情/对话脚本/`）。
- **★ 错位词**：主角冒出"手机 / 编译 / 改天"这类词时——
  - 该词**用特殊样式**（如描边 / 变色 / 轻微抖动）；
  - 旁边**闪一下"？"**（听者的困惑）；
  - **音效**：一声轻微的"失真"（可用 `public/sfx/kenney_sfx_*` 里的数字音）。
- **目的**：让玩家**立刻意识到"这里有个不属于这个世界的词"**——既是气氛，也是残魂的雷达。

## 七、菜单

| 项 | 内容 |
| --- | --- |
| **羁绊一览** | 所有已建立羁绊的角色（`flag.bond.*`），显示等级与是否达**生死之交 / 知己** |
| **残魂** | 见第五节 |
| **图鉴** | 见第四节（第五世后出现） |
