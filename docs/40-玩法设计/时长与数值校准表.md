# 时长与数值校准表（模板）

> **用途**：把**实测**填进来，和目标对比，再决定改不改。
> **态度**：**第一版不需要精确**——只要"大体能跑"。差值不大就别动。
> 填表时机：**每章第一次完整通关之后**。

---

**处理规则**

- 差值 **< −20%（太短）**：补**可选内容**，不补主线时长。

## 三、数值校准

> 测法：打同一场"标准战"，记录**回合数**与**主观手感**。

| 项 | 目标 | 实测 | 处理 |
| --- | --- | --- | --- |
| 一场普通战回合数 | 3–5 | | |
| 一场 Boss 战回合数 | 8–12 | | |
| `commandPower.spell`（法术 ×1.4） | 法术"够用" | | |
| `commandPower.skill`（特技 ×1.8） | 特技"更疼" | | |
| `commandPower.spiritTreasure`（灵宝 ×2.2） | 灵宝"很爽但有限" | | |
| 玩家每回合 SP 够不够放特技 | 约 2–3 回合攒够 | | |
| 逃跑成功率 | 不让人绝望 | | |
| 捕捉成功率 | 1–3 次能成 | | |

**处理规则**

- **主观手感**优先于数字：**"打起来不难受"** 就够。
- 只在**明显出问题**时改（如"法术完全没用"、"Boss 打了 30 回合"）。

## 四、残魂 / 羁绊 / 阵法 校准

| 项 | 目标 | 实测 | 处理 |
| --- | --- | --- | --- |
| 每章可拾取的游魂数 | ≤ 1（别让玩家漏太多） | | |
| 每章羁绊增长上限（`maxGainPerGeneration`） | 够到"生死之交" | | |
| 阵型加成是否"能感觉到" | 换位后手感有变 | | |
| 炼魂合成是否"能被试出来" | 玩家 3–5 次内悟到规则 | | |

---

## 五、填表纪律

1. **一次只改一个变量**，改完再测。
2. **第一版只记"太长 / 太短 / 够用"三档**，不做精细分析。
3. 任何改动**先回写**到：`战斗与成长.md`（数值）、`00-主线总纲.md` 第七节（时长）。
4. 本表是**工作稿**，允许潦草——**别为了填表而填表**。
