# 劫主 · 殷无咎

> ID：`char.yinwujiu`。**反派 / 主角的镜像**。上古封蚀之战的幸存者，长生者，主张「断轮」。

> 「无咎」取自《易》「无咎」——**没有过错**。这是他给自己的判词，也是他最深的讽刺：**他做了最错的事，却坚信自己没有错。**

## 外貌

- 一袭玄色长衣，赤足，发间缠着一缕**灰白的、不是头发的东西**（那是封印反噬留下的"蚀丝"）。
- 面容俊美而**空洞**——像一张画了很久、失了神的画。
- **他和主角有一个共同点：眼里都有"舍不得放下"的东西。** 区别是主角舍不得自己，殷无咎舍不得的**是另一个人**。

## 性格

- **不是暴君，是殉道者**。他冷静、有礼、甚至温和；杀人不皱眉，但对每一个死者都记得名字。
- **极度痛苦**：他是"最想死却死不了的人"。三千年了，他嫉妒每一个能安息的人。
- **说服力极强**：他的主张**在逻辑上几乎无可辩驳**——"轮回是苦，为何要延续？"。这正是本作最大的挑战：**玩家必须真的动摇过，才配得上最后的反选。**

## 背景故事

三千年前的封蚀之战，十二位合道修士以自身为祭封印「蚀」。**殷无咎是第十二人——他本该和其他十一人一起死去。**
但封印的反噬留了他一命：**他被永远钉在"活"的状态里，永失轮回。**

三千年间，他做了一件事：**读懂蚀。**
他发现蚀不是"恶"，蚀是**记忆的尽头、存在的尽头**。而轮回，正是"存在"用来对抗"被遗忘"的机制。
于是他得出一个**冰冷而自洽的结论**：

> **"若终将被遗忘，那从一开始就不该存在。与其痛苦地轮回，不如痛快地断掉。"**

这就是「**断轮**」（`concept.severing`）。

**他的私心**：三千年前，他拼命想救的那个人（见「执念」），正因为轮回而被一次次洗去、忘记。
**他恨的不是轮回，是"被忘记"。** 而主角，是这世上唯一**还记得一切**的人——所以他对主角的情感是**嫉妒 + 亲近 + 想拉他一起终结**。

### 执念（反派的情感核心）

三千年前，与他一同封印蚀的十一人中，有一个**他拼命想救却没能救下的人**。
那个人被忘川洗忆转生了一次又一次，**每一世都认不出他**。殷无咎守了那人三千年，看那人忘了自己三千次。

> **反转钩子**：那个人，与苏昭的灵魂有关。第七世揭示——**殷无咎守的，正是苏昭的前身**。
> 于是：主体（主角）与反派（殷无咎），**争的是同一个"被忘记的人"**。

## 属性与技能

- **境界**：超越合道（长生者的异常状态），但不稳定——**他每动用一次力量，就被蚀同化一分**。
- **能力**：不死不灭、通晓上古术法、能直接作用于灵魂（因此能与主角"隔世对话"）。
- **弱点（关键）**：他**无法自杀**，也无法被杀死——**只有主角能终结他**。这让他对主角又恨又求。
- **与 `CommandId` 的呼应**：他是唯一能同时使用**全部指令**的存在（普攻 / 法术 / 特技 / 法宝 / 灵宝 / 召唤 / 捕捉），但**每一招都在消耗他的"存在"**。

## 台词示例

**第三世，首次对荻青：**
> "我等你很久了。"
> "不必紧张。我不杀你——你死过，还会回来。我只想问一句："
> "你记得的那些人，还记得你吗？"

**第五世，听完沈无渡的反驳后：**
> "你说你靠'还有下一世'活下来。"
> "可你想过没有——那些等过你的人，他们只有一世。"
> "你记得他们。他们，不记得你。这不是恩赐……这是刑罚。"

**第七世，终局：**
> "我等三千年，不为毁掉这个世界。"
> "只为——让它**安静**下来。"
> "……你说，这算不算过分？"

（主角的回应当由玩家做出——这正是终局的第一个抉择。）
