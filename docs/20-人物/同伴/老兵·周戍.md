# 周戍

> ID：`char.npc.zhoushu`。第六世（`story.vol6`）的凡人队友之一，站在**1 号位**（输出）。

| 项 | 内容 |

| ID | `char.npc.zhoushu` |

| 阵营 | 凡人（`faction.dayan-court` 治下） |
| 首次登场 | 第六世（`story.vol6`） |

## 外貌

- 独眼（另一只眼留在战场上），脸上有一道从额角划到下颌的旧疤。
- 走路微微跛，但**站定的时候，比谁都稳**。
- 随身一杆早已不合制的旧枪，枪缨换过三次。

## 性格

- 沉默寡言，不擅长说漂亮话；**该他挡的时候，他从不往后缩**。
- **受过苦，但没被打坏**——他见过最坏的人心，仍选择站在人前面。
- 对柳眠（主角）的态度：一开始只是"收留一个无处可去的女子"，后来变成"这个姑娘比我们都会算"。

## 背景故事

十年前那场边关之败，他的营几乎全军覆没。**是一个不知名的同袍把他从死人堆里背了出来**。
他活到今天，一直觉得自己是"替那个人活着的"。
如今王朝将倾、苛税如虎，他在坊市里护着一群老弱——**不为朝廷，只为"当年有人这样护过我"**。

- **凡人，无灵根**。战力全凭**武艺与经验**。
- **兵种定位**：**1 号位 · 输出**（接受"阵法调整"的 `+atk` 类加成）。
- 特点：**血厚、耐打、越被压越稳**——是"前排"这两个字的字面意思。
