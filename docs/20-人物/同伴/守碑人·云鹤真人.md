# 云鹤真人

> ID：`char.yunhe`。**守碑人**——长生者，永失轮回。主角第一世的引路人。

## 基本信息

| 项 | 内容 |
| --- | --- |
| ID | `char.yunhe` |
| 本质 | 长生者（守碑人），**不能转世** |
| 身份 | 轮回碑的守护者；前后师从"守碑人"一脉 |
| 首次登场 | 第一世（`story.vol1`），青芜山 |
| 年龄 | 外表约六十岁，实际年龄**逾三千岁** |

## 外貌

- 一身洗得发白的灰布道袍，背微驼，拄一根不起眼的木杖。
- 眼睛**极亮**——像把一潭深水看穿了，看人时仿佛在看很久以前。
- **他不老，但也不活**：三千年里，他的脸几乎没有变化，只有眼神越来越倦。

## 性格

- **温和、絮叨，像个普通村口老头**——这是伪装，也是他真的想要的平凡。
- **极度疲惫**：守了三千年碑，见过太多"像主角一样的人"来过又走。
- **关键矛盾**：他**不能干预**——守碑人的职责只是"记录与看守"，不得改变碑上之事的走向。因此他眼睁睁看着主角一次次去死，却只能在旁边递一碗热汤。
- 他的温柔里藏着一把刀：**他早就知道主角会死，却不能说。**

## 背景故事

三千年前的**封蚀之战**，需要一个"守碑的人"——看守**轮回碑**（封蚀之阵的说明书）。
这份职责的代价是**永恒**：守碑人不入轮回，不得离开碑太远，也不得干预世间因果。

云鹤是这一脉的第几代守碑人，他自己都记不清了（因为守碑人之间会"交接"，交接的是职责与记忆，**不是同一个人**——这一点是后期的反转钩子）。

三千年来，他见过很多"不该记得前世的人"。**绝大多数最后都疯了。**
第一世的凌越，是三千年来**第一个没有疯的**。这让云鹤第一次生出了"想插手"的念头——**而这念头，正是第七世破局的第一块砖。**

> **反转钩子（第七世揭示）**：历代"云鹤真人"其实是**同一个灵魂的不同躯壳**，通过守碑的仪式强行续存——换句话说，**云鹤也是畸轮的一种，只是他自己不知道**。他与主角是一枚硬币的两面。

## 属性与技能

- **境界**：名义上"合道"，但因守碑之责**不得出手**（一旦出手即违背职责，会被碑反噬）。
- **能力**：知晓大量上古秘辛；能辨识"畸轮"；能短暂屏蔽轮回司的追踪。
- **限制（关键）**：**他不能说、不能救、只能看**。这个"限制"是剧本的**克制装置**——防止引路人直接剧透。

## 台词示例

**第一世，对年少的凌越：**
> "孩子，你昨夜又在哭。"
> "……梦见什么了？不要紧，梦见什么都不要紧。"
> "只是记住一件事：**你记得的那些，不是你的罪，是你的路。**"

**第一世，他临终（或别离）前：**
> "老朽活得太久了，久到忘了怎么难过。"
> "可你今天让我想起来了。"
> "……去吧。别回头。回头的人，走不远。"

**第七世，把钥匙交出去时：**
> "三千年了。我等过很多个'你'。"
> "他们都想问我是谁。你是第一个问我——'你累不累'的。"
